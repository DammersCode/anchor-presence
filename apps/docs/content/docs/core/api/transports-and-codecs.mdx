## TransportClose

`TransportClose` is the value that a transport gives to `subscribeClose` listeners when a connection closes. See [Transports](/docs/core/transports#close-reasons).

Import the type from `@anchor-presence/core`:

```ts
import type { TransportClose } from "@anchor-presence/core";
```

## createInMemoryPair

Import `createInMemoryPair` from `@anchor-presence/core`:

```ts
import { createInMemoryPair } from "@anchor-presence/core";
```

`createInMemoryPair(options?)` returns two transports wired to each other. See [In-memory transport](/docs/core/in-memory-transport).

`InMemoryTransport` is the type of `a` and `b`. It is a `LiveCursorTransport` that always has `connect`, `disconnect`, `subscribeStatus`, and `getStatus`.

## jsonCodec and binaryCodec

Import the two codecs from `@anchor-presence/core`:

```ts
import { jsonCodec, binaryCodec } from "@anchor-presence/core";
```

`jsonCodec` is the default codec. `binaryCodec` is a compact binary codec with a fixed layout. See [Codecs](/docs/core/codecs#choose-a-codec) to choose between them, and [Binary codec](/docs/core/binary-codec) for the wire layout.

Both codecs carry leave messages and events. See [Leave and event messages](/docs/core/api/protocol#leave-and-event-messages).
