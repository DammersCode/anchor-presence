You want a relay that runs on plain Node.js, with a well-known WebSocket library. This example uses [`ws`](https://github.com/websockets/ws) over `node:http`. The relay keeps each room as a `Set` of sockets and sends to each one. As a result, it can skip sends to a slow receiver.

## Run it

Start the entry file with Bun, or with Node.js 22.18 or later:

```sh
bun relay.ts
# On Node.js 22.18 or later:
node relay.ts
```

Node.js runs the TypeScript files directly, with type stripping. For this reason, the imports use `.ts` extensions. In a clone of the repository, `bun run dev:relay` and `bun run dev:relay:node` in `examples/node-ws` run the same two commands.

The relay listens on `http://localhost:8789`. To use a different port, give the port as the first argument.

## Behavior notes

Each setting is an environment variable. The factory options `maxMessageBytes`, `rateCapacity`, `rateRefillPerSecond`, `maxRoomSockets`, `maxSockets`, `idleTimeoutSeconds`, `slowPeerSoftBytes`, `slowPeerHardBytes`, `slowPeerResumeBytes`, `allowedOrigins` and `authCheck` override them.

### What the relay does

| Topic            | Behavior                                                                                                                                           |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Room             | Reads `room` from the query. A missing value is `main`. An invalid name closes the socket with code `4007`.                                        |
| Upgrade path     | Accepts the upgrade only at `/`. Any other path gets HTTP `404`.                                                                                   |
| Fan-out          | Sends to every other open socket in the room `Set`.                                                                                                |
| Payload          | Forwards each frame unchanged. Decodes a frame only for identity binding.                                                                          |
| Dead connections | Pings each socket every half of `RELAY_IDLE_TIMEOUT_SECONDS` (60, so every 30 seconds). Terminates a socket that did not answer the previous ping. |
| Send batching    | Corks the socket of each receiver and flushes it once per event-loop turn. Each receiver gets one write per turn, not one write per frame.         |
| Room cleanup     | Drops the room entry when its last socket closes.                                                                                                  |

### Limits

The relay reads the limits, the defaults, and the codes on [Deploy a relay](/docs/get-started/guides/deploy-relay#set-the-environment-variables). The relay sets the hard frame size with the `maxPayload` option of `ws`.

The relay reads the send buffer of a receiver from `bufferedAmount`.

### Auth

| Check            | Setting                                                                              | On refusal                                        |
| ---------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------- |
| Origin           | `RELAY_ALLOWED_ORIGINS`, comma-separated. Empty allows every origin.                 | Upgrades, then closes with code `4004`.           |
| Room token       | `RELAY_AUTH_TOKEN`. Compares the `token` query parameter. Empty turns the check off. | Closes with code `4006`.                          |
| `authCheck` hook | Factory option. Replaces the room token check.                                       | Closes with code `4006` on `false` or an error.   |
| Identity binding | `authCheck` returns `{ clientId, user }`.                                            | Closes the sender with code `1008`.               |
| Check order      | Origin, then room name, then the hook.                                               | The hook never runs for a refused origin or room. |

See [Demo identity mode](/docs/examples/backends/relay-contract#demo-identity-mode).

<Callout type="warn">
  If you expose this relay outside local development, set `RELAY_ALLOWED_ORIGINS` and `RELAY_AUTH_TOKEN`. Also
  put a proxy that serves TLS (`wss://`) in front of the relay. Without them, any page and any visitor can
  join a room.
</Callout>
