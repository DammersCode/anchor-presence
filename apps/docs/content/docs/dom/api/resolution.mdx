The resolution result has the types below. See [Resolution](/docs/dom/resolution) and [Visibility policy](/docs/dom/visibility-policy) for the guides.

Import the types from `@anchor-presence/dom`:

```ts
import type { ResolvedCursor, ResolutionTier, VisibilityPolicy } from "@anchor-presence/dom";
```

## ResolvedCursor

A `ResolvedCursor` is one resolved remote cursor, in the viewport pixels of the receiver.

## ResolutionTier

`ResolutionTier` is a union of three string values: `"anchor"`, `"viewport"`, `"hidden"`. See [Resolution](/docs/dom/resolution) for what each tier means.

## CURSOR_MARKER_ATTRIBUTE

`CURSOR_MARKER_ATTRIBUTE` is the string `"data-anchor-presence-cursor"`. The binding ignores the DOM changes inside an element with this attribute. A renderer that draws cursors sets it on the root element of each cursor. `@anchor-presence/react` sets it for you. See [Draw cursors without React](/docs/dom/binding#draw-cursors-without-react).
