An anchor is an element that a remote cursor can point at. Each anchor has a stable ID. The sender sends the ID and a point inside the anchor, and the receiver finds its own element with the same ID. Put anchors on the elements that matter to your users: a button, a table row, a sidebar link.

## Mark an anchor

Add the `data-anchor` attribute. Its value is the anchor ID:

```tsx
<button data-anchor="nav.dashboard">Dashboard</button>
```

The binding finds and registers every element with the attribute. It needs no other call. To use another attribute name, set `anchorAttribute` in [`DomBindingOptions`](/docs/dom/api/binding). [Anchor registration](/docs/dom/anchor-registration) explains automatic registration, empty values, and shadow DOM.

## Anchor IDs

An anchor ID is a string of 1 to 256 characters. The library gives it no meaning, so you choose the naming scheme. Examples are `nav.dashboard`, `stats.revenue`, and `orders.row:17.actions`.

- Give one element the same ID in every layout and every UI state. Then the receiver always finds it.
- Do not create a new ID on each render for the same element.
- If two elements use one ID, the newest element wins. See [Duplicate IDs](/docs/dom/anchor-registration#duplicate-ids).

Anchor IDs are map keys only. They never become CSS selectors or code. A remote message can only address an element that your app registered. See [Security](/docs/get-started/guides/security#why-anchor-ids-never-touch-selectors).

## Normalized u/v coordinates

The position inside an anchor has two numbers, `u` and `v`, from 0 to 1:

- `u` is the horizontal position: 0 at the left edge, 1 at the right edge.
- `v` is the vertical position: 0 at the top edge, 1 at the bottom edge.

The sender computes them from its own rectangle of the anchor:

```text
u = (pointerX - rect.left) / rect.width
v = (pointerY - rect.top) / rect.height
```

The receiver applies the same fraction to its own rectangle of the anchor. A point at 75% of the width stays at 75%, even if the anchor has a different size on each screen. [Responsive layouts](/docs/get-started/concepts/responsive-layouts) shows a worked example. [Resolution](/docs/dom/resolution) gives the pixel formula. The receiver clamps `u` and `v` to the range 0 to 1.
