## createWebSocketTransport

`createWebSocketTransport(options?)` returns a `WebSocketTransport`: a `LiveCursorTransport` from `@anchor-presence/core` whose `connect` and `disconnect` methods are always present, not optional.

## WebSocketCtor

`WebSocketCtor` overrides the WebSocket constructor the transport uses, and defaults to `globalThis.WebSocket`. It exists so a test can supply a fake `WebSocketLike` implementation without touching the real network stack.
