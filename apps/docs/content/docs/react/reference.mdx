## Hooks

| Hook                                         | Returns                                                                |
| -------------------------------------------- | ---------------------------------------------------------------------- |
| `useRemoteUsers()`                           | one entry per remote client: `clientId`, `user`, `session`, and `idle` |
| `useRemoteCursors()`                         | `ResolvedCursor[]` snapshot                                            |
| `useRemoteCursorsSelector(select, isEqual?)` | a value derived from the snapshot                                      |
| `useCursorPresence()`                        | raw remote `RemotePresence<TContext, TUser>[]`                         |
| `useCursorStatus()`                          | `ConnectionStatus`                                                     |
| `useCursorClient()`                          | the `PresenceClient` instance, or `null`                               |
| `useCursorContext()`                         | `[context, setContext]`                                                |

Every hook's render cost is documented in the [React guide](/docs/guides/react#render-cost).

## Re-exported types

`@anchor-presence/react` re-exports the `core` and `dom` types its own signatures use, so most apps need no direct dependency on those packages for types:

```ts
import type {
  AnchorPoint,
  ConnectionStatus,
  CursorPosition,
  CursorPresence,
  Interpolator,
  InterpolatorFactory,
  PresenceClient,
  RemotePresence,
} from "@anchor-presence/react";
import type { DomBinding, DomBindingOptions, ResolutionTier, ResolvedCursor } from "@anchor-presence/react";
```
