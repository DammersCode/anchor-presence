## useCursorStatus

```ts
function useCursorStatus(): ConnectionStatus;
```

Returns one of `"connecting"`, `"connected"`, `"reconnecting"`, `"disconnected"`. See [Connection status](/docs/react/connection-status).

## useCursorClient

```ts
function useCursorClient<TContext = unknown, TUser = unknown>(): PresenceClient<TContext, TUser> | null;
```

Returns the client of the nearest `LiveCursorProvider`, or `null` outside a provider or during server rendering.

## useCursorEvents

```ts
function useCursorEvents(listener: (event: RemoteEvent) => void): void;
```

Calls `listener` for each event that a remote peer sends with `client.sendEvent`. `RemoteEvent` has a `type`, an optional `data`, and the `clientId` of the sender. See [Cursor events](/docs/react/cursor-events).
