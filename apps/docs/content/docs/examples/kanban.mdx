title: Kanban board
description: A board of fixed-size cards that scrolls when the pane shrinks, so cursors stay on their cards.
---

When the pane shrinks, this layout keeps every card and column at the same size and position. The board scrolls instead of squishing the columns. In this demo, both panes show the same board. The wide pane fits all three columns. The narrow pane shows two columns. The board scrolls to the third.

<ExamplePreview scene="kanban" />

## What's in the demo

- The columns keep a fixed width in both panes. The board row is a horizontal scroll container.
- Select the `+` button in a column header to add a card. Select the `X` button on a card to delete it. A cursor on a deleted card falls back to the column.
- The tour points at a card in the third column. The narrow pane hides that card. A colored button at the board edge shows where the cursor is. Select it to scroll the card into view.
- Columns and cards have the same size and position in both panes. A cursor on a visible card moves the same distance in both panes.
