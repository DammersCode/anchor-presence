`CursorLayer` renders `DefaultCursor` by default. `renderCursor` replaces the visual, and `CursorLayer` keeps control of the position and the pointer events. In this demo, the same remote cursor shows as a name pill in the wide pane and as an avatar in the narrow pane.

`CursorLayer` puts the root of each cursor at the cursor point. A renderer draws relative to that point. The crosshair moves its SVG up and to the left, so that the center of the crosshair is on the point.

Pick cursor colors that reach WCAG AA contrast (4.5:1) against the label text.

<Callout type="warn">
  If a custom renderer shows `cursor.user`, it shows untrusted network data. Render it as text, never as HTML.
</Callout>

## Behavior notes

- Four renderers: the default arrow, a name pill, an avatar with initials, and a crosshair with the receiver coordinates.
- Select a renderer in either pane. Each pane has its own setting, because the receiver renders the cursor.
- The crosshair shows `cursor.x` and `cursor.y`. The numbers are different in the two panes, because each pane resolves the anchor in its own layout.
