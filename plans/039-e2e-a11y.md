# 039 E2E coverage for the new behavior

Status: open · Branch: `audit-improvements` · Part of [030](030-multi-audit.md)

Goal: lock in modal stacking, keyboard-focus cursors, and touch clear with Playwright.

Requires steps 035, 037, 038.

## Changes

- New `e2e/keyboard-and-modal.spec.ts` (or extend `e2e/a11y.spec.ts`; follow `playwright-best-practices` and the existing spec style, `openPair`/`moveToAnchor` helpers from `e2e/helpers.ts`):
  1. Modal stacking: open the settings dialog on the receiver, move the sender mouse onto the dialog area, and assert `document.elementFromPoint` at the remote cursor's position resolves to the cursor element (not the dialog) — the cursor renders above the overlay.
  2. Keyboard focus: the sender focuses an element (`page.keyboard.press("Tab")` or `element.focus()`), then the receiver's cursor appears near that element's rect (`expectRemoteCursorNear` against the anchor's box).
  3. Touch clear: the sender does `page.touchscreen.tap` on an anchor; the receiver's cursor is visible while the touch is down and disappears after `pointerup` (poll until invisible, bounded timeout).
- Keep each case small and independent (own room via `uniqueRoom`).

## Verify

- `bunx playwright test --project=chromium e2e/keyboard-and-modal.spec.ts`, then the full suite for gate 6. Rerun a single failing browser test once before debugging (repo convention).
