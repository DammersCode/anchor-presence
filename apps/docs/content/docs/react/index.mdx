`@anchor-presence/react` connects a presence client to React. Use it in a React app that shows the cursors of other users. It gives you one provider, hooks that read presence data, and two components that draw cursors.

## Minimal setup

This app connects to the Bun relay of the [Quick start](/docs/get-started/quick-start#connect-a-relay), on port 8788. It renders the cursors of every peer:

```tsx
import { createPresenceClient } from "@anchor-presence/core";
import { createWebSocketTransport } from "@anchor-presence/dom";
import { CursorLayer, PresenceProvider } from "@anchor-presence/react";

function App() {
  return (
    <PresenceProvider
      factory={() => {
        const transport = createWebSocketTransport({ port: 8788, path: "/?room=main" });
        return createPresenceClient({ transport });
      }}
    >
      <Dashboard />
      <CursorLayer />
    </PresenceProvider>
  );
}
```

Until the factory runs, the provider renders its children with no cursors. For the anchor markup and the relay, follow the [Quick start](/docs/get-started/quick-start).

## Package facts

- The package has no state store of its own. The hooks read the client from `@anchor-presence/core` and the binding from `@anchor-presence/dom`.
- The package entry starts with `"use client"`. In a framework with React Server Components, its exports are Client Components. See [Frameworks](/docs/get-started/frameworks).
- The peer range is `>=18`. CI runs the tests on React 19.
- In development mode, the provider and the hooks write console warnings for setup errors. See [Development warnings](/docs/get-started/guides/troubleshooting#development-warnings).
