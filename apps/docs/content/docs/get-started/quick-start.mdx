This page runs live cursors two ways: first with no backend, using an in-process transport, then with a real relay between two browser tabs.

## Try it with no backend

`createInMemoryPair` gives you two connected transports in one process. Use it to see the library work before you wire up a relay:

```tsx
import { createInMemoryPair, createPresenceClient } from "@anchor-presence/core";
import { LiveCursorProvider, CursorLayer } from "@anchor-presence/react";

const { a: transport } = createInMemoryPair();
const client = createPresenceClient({ transport, user: { name: "Alice" } });

function DashboardButton() {
  return <button data-anchor="nav.dashboard">Dashboard</button>;
}

function App() {
  return (
    <LiveCursorProvider client={client}>
      <DashboardButton />
      <CursorLayer />
    </LiveCursorProvider>
  );
}
```

This client only talks to itself: `transport.a`'s messages go to `transport.b`'s listeners, and nothing else holds `transport.b`. It is enough to render the tree and check that anchors, the provider, and `CursorLayer` compile and mount. It is also how the docs site tests every sample on this page.

## Connect two real clients

Real live cursors need two clients, one per browser tab, talking over a shared transport. Pass the provider a `factory`. It runs the factory once, in a mount effect. Then React Strict Mode's double-invoke in development creates only one client:

```tsx
import { createPresenceClient } from "@anchor-presence/core";
import { createWebSocketTransport } from "@anchor-presence/dom";
import { CursorLayer, LiveCursorProvider } from "@anchor-presence/react";

function App() {
  return (
    <LiveCursorProvider
      factory={() => {
        const transport = createWebSocketTransport({ path: "/?room=main" });
        return createPresenceClient({ transport, user: { name: "Alice" } });
      }}
    >
      <button data-anchor="nav.dashboard">Dashboard</button>
      <CursorLayer />
    </LiveCursorProvider>
  );
}
```

The client connects the transport by default. Until the mount effect has run, the provider renders its children with a `null` client, and every hook returns its server-safe value. See [SSR and Strict Mode](/docs/react/ssr-and-strict-mode) for the full rule.

Copy a relay from [Backends](/docs/examples/backends) to pair with it. [Bun](/docs/examples/backends/bun-native) is the smallest runnable relay.

`room` is a relay-side grouping key, not part of the protocol. Any bidirectional byte channel that implements the transport interface works in place of `createWebSocketTransport`. See [Transports](/docs/core/transports).

## Without React

`@anchor-presence/core` and `@anchor-presence/dom` work with no React in the tree. Subscribe to the binding's resolved cursors directly and render them yourself in plain DOM updates or another framework. See [Binding](/docs/dom/binding) for the subscribe method, and [Build a framework adapter](/docs/core/build-a-framework-adapter) if you want to connect the binding to a framework's own reactivity.
