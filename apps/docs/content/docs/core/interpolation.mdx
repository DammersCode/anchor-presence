An `Interpolator` eases the position of a remote cursor toward its last target, so the cursor does not jump on every message. `@anchor-presence/dom` creates one interpolator for each peer through an `InterpolatorFactory`. If you want another easing style, for example a spring, write your own interpolator.

## Use an interpolator

`linearInterpolator(durationMs?)` returns an `Interpolator`:

```ts
import { linearInterpolator } from "@anchor-presence/core";

const interpolator = linearInterpolator(80);
```

Pass a factory to the DOM binding through `resolution.interpolatorFactory`. See [Motion](/docs/dom/motion#choose-a-custom-interpolator).

## The Interpolator interface

`@anchor-presence/core` exports `Interpolator` and `InterpolatorFactory` with these shapes:

```ts
interface Interpolator {
  target(x: number, y: number, timestampMs: number): void;
  shift(dx: number, dy: number): void;
  sample(timestampMs: number): { x: number; y: number; settled: boolean };
  sampleInto?(out: { x: number; y: number; settled: boolean }, timestampMs: number): void;
  reset?(): void;
}

type InterpolatorFactory = () => Interpolator;
```

| Method       | Job                                                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------------------------------------- |
| `target`     | Sets a new position to ease toward. The ease starts from the current eased position.                                      |
| `shift`      | Moves the current position and the target by a delta, and does not restart the ease.                                      |
| `sample`     | Returns the eased position at a timestamp. `settled` is `true` when the position reaches its target.                      |
| `sampleInto` | Optional. Writes the same result into `out` and creates no object.                                                        |
| `reset`      | Optional. Clears the ease state. The next `target` call then jumps to the new position and does not ease from an old one. |

The DOM binding calls these methods at fixed points:

- It calls `shift` when a local scroll or layout change moves the cursor and no new message arrived. A running ease then continues from the new place.
- It calls `sampleInto` on each frame when the interpolator has it, and `sample` otherwise.
- It calls `reset` on each frame while the cursor has the `hidden` tier. A cursor that the visibility policy hides keeps its ease state.
- It asks for another frame while `settled` is `false`. An interpolator that never settles keeps the frame loop running.

## Write a spring

This factory eases a cursor with a damped spring. A new `target` keeps the velocity, so the cursor curves toward the new place:

```ts
import type { InterpolatorFactory } from "@anchor-presence/core";

const STIFFNESS = 120;
const DAMPING = 13;
const MAX_STEP_MS = 64;

const mySpringInterpolatorFactory: InterpolatorFactory = () => {
  let x = 0;
  let y = 0;
  let velocityX = 0;
  let velocityY = 0;
  let targetX = 0;
  let targetY = 0;
  let lastMs = 0;
  let started = false;
  let settled = true;

  return {
    target(nextX, nextY, timestampMs) {
      if (!started) {
        x = nextX;
        y = nextY;
        started = true;
      }
      if (settled) lastMs = timestampMs;
      targetX = nextX;
      targetY = nextY;
      settled = false;
    },
    shift(dx, dy) {
      x += dx;
      y += dy;
      targetX += dx;
      targetY += dy;
    },
    sample(timestampMs) {
      const dt = Math.min(Math.max(timestampMs - lastMs, 0), MAX_STEP_MS) / 1000;
      lastMs = timestampMs;
      if (settled) return { x, y, settled };
      velocityX += (-STIFFNESS * (x - targetX) - DAMPING * velocityX) * dt;
      velocityY += (-STIFFNESS * (y - targetY) - DAMPING * velocityY) * dt;
      x += velocityX * dt;
      y += velocityY * dt;
      if (Math.hypot(velocityX, velocityY) < 50 && Math.hypot(x - targetX, y - targetY) < 0.05) {
        x = targetX;
        y = targetY;
        velocityX = 0;
        velocityY = 0;
        settled = true;
      }
      return { x, y, settled };
    },
  };
};
```

## linearInterpolator

The interpolator from `linearInterpolator` eases linearly over a fixed duration, `80` milliseconds by default. The first `target` call jumps to the position, because there is no previous position to ease from. A duration of `0` or less jumps on every `target` call.

`linearInterpolator` itself also fits `InterpolatorFactory`, with the default duration. For another duration, pass a factory that calls `linearInterpolator`:

```ts
const factory = () => linearInterpolator(120);
```

## noneInterpolator

`noneInterpolator` is an `InterpolatorFactory`. Import it from `@anchor-presence/core`:

```ts
import { noneInterpolator } from "@anchor-presence/core";
```

An interpolator from `noneInterpolator` applies no easing. `sample` always returns the last target, with `settled: true`. If peers send messages at a high rate and you need no smoothing between updates, use it. The DOM binding uses it by default when the operating system asks for reduced motion.
