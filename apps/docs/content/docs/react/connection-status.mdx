`usePresenceStatus` returns the connection status of the client from the nearest provider. Use it to show a reconnect banner, or to disable UI that needs presence while the connection is down.

## Usage

This component shows the status while the client is not connected:

```tsx
import { usePresenceStatus } from "@anchor-presence/react";

function ConnectionBanner() {
  const status = usePresenceStatus();
  if (status === "connected") return null;
  return <div role="status">{status}</div>;
}
```

## Status values

The status is one of `"connecting"`, `"connected"`, `"reconnecting"`, or `"disconnected"`. The hook rerenders only when the status changes.

The hook returns `"disconnected"` without a provider. It returns `"connecting"` before the provider `factory` runs, also on the server render.

<Callout type="warn">
  If a banner renders on the first paint, it shows `"connecting"` for a short time, before the client exists.
  Show the banner only after the status stays not connected for 1 to 2 seconds.
</Callout>

This component waits 1.5 seconds before it shows the banner:

```tsx
import { useEffect, useState } from "react";
import { usePresenceStatus } from "@anchor-presence/react";

function DelayedConnectionBanner() {
  const status = usePresenceStatus();
  const connected = status === "connected";
  const [show, setShow] = useState(false);

  useEffect(() => {
    if (connected) return;
    const timer = setTimeout(() => setShow(true), 1500);
    return () => {
      clearTimeout(timer);
      setShow(false);
    };
  }, [connected]);

  return show ? <div role="status">{status}</div> : null;
}
```

## Cursors during an outage

While the status is `"reconnecting"` or `"disconnected"`, the binding hides every remote cursor. `useRemoteCursors` then returns an empty list, and `CursorLayer` renders no cursors. When the status returns to `"connected"`, the cursors come back. A banner tells the user why the cursors are gone.

## Close reasons

`client.subscribeClose(listener)` calls the listener each time the connection closes. The listener receives the close `code`, the `reason`, and `willReconnect`. The WebSocket transport reports these values. A transport without `subscribeClose` never calls the listener.

This component shows an error when the relay rejects the [room token](/docs/dom/websocket-transport#room-token) with code `4006`:

```tsx
import { useEffect, useState } from "react";
import { usePresenceClient } from "@anchor-presence/react";

function TokenError() {
  const client = usePresenceClient();
  const [closeCode, setCloseCode] = useState<number | null>(null);

  useEffect(
    () =>
      client?.subscribeClose((close) => {
        if (!close.willReconnect) setCloseCode(close.code ?? null);
      }),
    [client],
  );

  if (closeCode !== 4006) return null;
  return <div role="alert">The relay rejected the room token.</div>;
}
```
