An app with live cursors usually also wants a simple roster: who is here right now, independent of where their cursor is. `useRemoteUsers` gives you that list without subscribing to cursor movement.

## Code

```tsx
import { useRemoteUsers } from "@anchor-presence/react";

type DemoUser = { name: string; color: string };

export function WhoIsOnline() {
  const users = useRemoteUsers<DemoUser>();
  return (
    <div className="fixed right-4 bottom-4 flex items-center gap-2 rounded-full border bg-white px-3 py-1.5 shadow-sm">
      <span className="text-xs font-medium">{users.length} online</span>
      <div className="flex items-center -space-x-1.5">
        {users.map((u) => (
          <span
            key={u.clientId}
            title={u.user?.name ?? u.clientId.slice(0, 6)}
            className="h-2.5 w-2.5 rounded-full ring-1 ring-white"
            style={{ backgroundColor: u.user?.color ?? "#6b7280" }}
          />
        ))}
      </div>
    </div>
  );
}
```

## Behavior notes

- `useRemoteUsers` rerenders only when the set of remote clients, or their `user`, `session`, or `idle` state, changes. It does not rerender on cursor movement, so a presence bar built from it costs nothing while cursors move.
- `user` is untrusted network data. Render `u.user?.name` as text, as shown above; never interpolate it into HTML.
- A client is `idle` after `idleAfterMs` (default 15000 ms) with no message. Show idle users dimmed or with an "away" label. The store removes the client later, after `staleTimeoutMs`.
- A client appears in this list even if its cursor currently resolves to `hidden`. Presence and cursor visibility are two different signals.
