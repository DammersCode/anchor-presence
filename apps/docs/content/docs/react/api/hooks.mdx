## useCursorStatus

```ts
function useCursorStatus(): ConnectionStatus;
```

Returns one of `"connecting"`, `"connected"`, `"reconnecting"`, `"disconnected"`. See [Connection status](/docs/react/connection-status).

## useCursorClient

```ts
function useCursorClient<TContext = unknown, TUser = unknown>(): PresenceClient<TContext, TUser> | null;
```

Returns the client instance passed to `LiveCursorProvider`, or `null` outside a provider or during server rendering.
