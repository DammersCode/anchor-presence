This page lists the signature of every hook in `@anchor-presence/react`, and of `createPresenceHooks`. Use it to look up a type. For usage, render cost, and examples, read the guide page that each section links to. A peer is another client in the same room.

Every hook reads the nearest `LiveCursorProvider`. Without a provider, each hook returns its empty value, and in development mode one console warning appears. For the empty values, see [Server-safe values](/docs/react/ssr-and-strict-mode#server-safe-values).

## useRemoteCursors

```ts
function useRemoteCursors<TContext = unknown, TUser = unknown>(): ResolvedCursor<TContext, TUser>[];
```

Returns the resolved cursor of every peer, hidden cursors included. Guide: [Remote cursors](/docs/react/remote-cursors).

## useRemoteCursorsSelector

```ts
function useRemoteCursorsSelector<TSelected, TContext = unknown, TUser = unknown>(
  select: (cursors: ResolvedCursor<TContext, TUser>[]) => TSelected,
  isEqual?: (a: TSelected, b: TSelected) => boolean,
): TSelected;
```

Returns `select` applied to the resolved cursors. `isEqual` defaults to `Object.is`. Guide: [Select a smaller value](/docs/react/remote-cursors#select-a-smaller-value).

## useRemotePresence

```ts
function useRemotePresence<TContext = unknown, TUser = unknown>(): RemotePresence<TContext, TUser>[];
```

Returns the raw presence of every peer, in the coordinates of the sender. Guide: [Remote presence](/docs/react/remote-presence).

## useLocalUser

```ts
function useLocalUser<TUser = unknown>(): [TUser | undefined, (next: TUser | undefined) => void];
```

Returns the local `user` value and a setter that calls `client.setUser`. Guide: [Local user](/docs/react/local-context#local-user).

## useLocalContext

```ts
function useLocalContext<TContext = unknown>(): [TContext | undefined, (next: TContext | undefined) => void];
```

Returns the local context value and a setter that calls `client.setContext`. Guide: [Local context](/docs/react/local-context#local-context).

## useCursorStatus

```ts
function useCursorStatus(): ConnectionStatus;
```

Returns `"connecting"`, `"connected"`, `"reconnecting"`, or `"disconnected"`. Guide: [Connection status](/docs/react/connection-status).

## useCursorClient

```ts
function useCursorClient<TContext = unknown, TUser = unknown>(): PresenceClient<TContext, TUser> | null;
```

Returns the client of the nearest provider, or `null` without one. On the server, it returns the `client` prop of the provider. A provider with only a `factory` has no client on the server, so the hook returns `null`.

## useCursorBinding

```ts
function useCursorBinding<TContext = unknown, TUser = unknown>(): DomBinding<TContext, TUser> | null;
```

Returns the DOM binding of the nearest provider. It returns `null` before the provider creates the binding, and without a provider. On the server, it returns the `binding` prop of the provider, or `null` without that prop.

If state that a `visibilityPolicy` reads changes, call `binding.invalidate()`. See [Run the policy again after a state change](/docs/dom/visibility-policy#run-the-policy-again-after-a-state-change).

## useCursorEvents

```ts
function useCursorEvents(listener: (event: RemoteEvent) => void): void;
```

Calls `listener` for each event that a peer sends with `client.sendEvent`. `RemoteEvent` has a `type`, an optional `data`, and the `clientId` of the sender. Guide: [Cursor events](/docs/react/cursor-events).

## usePeerChanges

```ts
function usePeerChanges<TContext = unknown, TUser = unknown>(
  listener: (change: PeerChange<TContext, TUser>) => void,
): void;
```

Calls `listener` when a peer joins, leaves, or changes its `user` or `context`. Guide: [Peer changes](/docs/react/remote-users#peer-changes).

## useSendEvent

`useSendEvent` exists only in the result of `createPresenceHooks`. It returns a function of the type `EventChannel<TEvents>["send"]`. Without a client, the function returns `false`. Guide: [Typed events](/docs/react/typed-hooks#typed-events).

## createPresenceHooks

`createPresenceHooks` returns the provider and the hooks with your types fixed:

```ts
function createPresenceHooks<TContext = unknown, TUser = unknown, TEvents extends object = EventMap>(): {
  LiveCursorProvider: (props: LiveCursorProviderProps<TContext, TUser>) => ReactNode;
  useCursorBinding: () => DomBinding<TContext, TUser> | null;
  useCursorClient: () => PresenceClient<TContext, TUser> | null;
  useLocalContext: () => [TContext | undefined, (next: TContext | undefined) => void];
  useCursorEvents: (listener: (event: TypedRemoteEvent<TEvents>) => void) => void;
  useRemotePresence: () => RemotePresence<TContext, TUser>[];
  useCursorStatus: () => ConnectionStatus;
  useRemoteCursors: () => ResolvedCursor<TContext, TUser>[];
  useRemoteCursorsSelector: <TSelected>(
    select: (cursors: ResolvedCursor<TContext, TUser>[]) => TSelected,
    isEqual?: (a: TSelected, b: TSelected) => boolean,
  ) => TSelected;
  useRemoteUsers: () => RemoteUser<TUser>[];
  useLocalUser: () => [TUser | undefined, (next: TUser | undefined) => void];
  usePeerChanges: (listener: (change: PeerChange<TContext, TUser>) => void) => void;
  useSendEvent: () => EventChannel<TEvents>["send"];
};
```

`TEvents` is an event map. The `useCursorEvents` of the result passes a `TypedRemoteEvent<TEvents>` to the listener. Guide: [Typed hooks](/docs/react/typed-hooks).

## Re-exported types

The package re-exports the types that its signatures use, so you can import them from `@anchor-presence/react`:

- From `@anchor-presence/core`: `AnchorPoint`, `ConnectionStatus`, `CursorPosition`, `CursorPresence`, `EventChannel`, `EventMap`, `Interpolator`, `InterpolatorFactory`, `PeerChange`, `PresenceClient`, `PresenceEvent`, `RemoteEvent`, `RemotePresence`, and `TypedRemoteEvent`. See the [protocol types](/docs/core/api/protocol) and the [client API](/docs/core/api/client).
- From `@anchor-presence/dom`: `DomBinding`, `DomBindingOptions`, `ResolutionTier`, and `ResolvedCursor`. See the [binding API](/docs/dom/api/binding) and the [resolution API](/docs/dom/api/resolution).
