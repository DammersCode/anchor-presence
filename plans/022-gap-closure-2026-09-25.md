## Not planned

- Relay egress grows with room size × senders. This is documented in the performance guide.
- iframe anchors: document the limit, no support.
- Cursor collision avoidance: `renderCursor` is the customization point.

## Spec decisions

- Reduced motion: with `prefers-reduced-motion: reduce`, remote cursors snap to the resolved position. No new option unless an interpolation option already exists.
- Idle stage: a peer with no update for `idleAfterMs` is idle. The React cursor renders idle peers dimmed. The stale timeout still removes the peer.
- Off-screen: the library exposes a flag. Edge-indicator UI is app code.
- Benchmarks: `tinybench` script, `bun run bench`. It fails when an operation is slower than the committed baseline × 3. `--update-baseline` rewrites the baseline.
- CI: `concurrency` group per ref, Bun cache, jobs for docs build and SignalR (.NET). Chromium e2e stays the only browser in CI.
- New e2e tests: in-place socket drop and reconnect, and room isolation.
