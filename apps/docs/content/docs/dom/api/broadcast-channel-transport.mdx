This page lists `createBroadcastChannelTransport` and its type. The [BroadcastChannel transport](/docs/dom/broadcast-channel-transport) guide explains the behavior. Import them from the package:

```ts
import { createBroadcastChannelTransport } from "@anchor-presence/dom";
import type { BroadcastChannelTransport } from "@anchor-presence/dom";
```

## createBroadcastChannelTransport

`createBroadcastChannelTransport(channelName: string): BroadcastChannelTransport` returns a transport for one channel name. It does not open the `BroadcastChannel` until `connect()`, so it never throws at creation.

## BroadcastChannelTransport

`BroadcastChannelTransport` is a `PresenceTransport` from `@anchor-presence/core` whose `connect`, `disconnect`, `subscribeStatus`, and `getStatus` methods are required. It has no `subscribeClose` and no `bufferedBytes`.
