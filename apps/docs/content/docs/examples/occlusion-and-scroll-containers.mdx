---
title: Occlusion and scroll containers
description: Hide a cursor that resolves inside a scrolled-away part of a container.
---

An anchor inside a scrollable panel can be measurable, with a real size and position, while the scroll container clips the resolved point out of view. Without a policy for this, the cursor floats over the panel's visible edge instead of disappearing.

<InstallCommand />

## Code

```ts
import type { VisibilityPolicy } from "@anchor-presence/dom";

const clippedPointPolicy: VisibilityPolicy = ({ resolution }) =>
  !resolution.pointVisible || resolution.tier === "hidden" ? "hide" : "show";
```

```tsx
<LiveCursorProvider client={client} bindingOptions={{ resolution: { visibilityPolicy: clippedPointPolicy } }}>
  <ScrollPanel />
  <CursorLayer />
</LiveCursorProvider>
```

## Behavior notes

- This demo's scroll panel triggers the clip, so `clippedPointPolicy` hides the cursor while the panel is scrolled away from the anchor.
- The demo's fallback chain has no other anchor to degrade to, so the visible choice is between showing a floating cursor and hiding it.

See [Occlusion and scroll](/docs/dom/occlusion-and-scroll) for how the resolver detects a clipped point and what `pointVisible` does not cover.
