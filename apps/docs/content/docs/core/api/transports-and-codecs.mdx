## jsonCodec and binaryCodec

```ts
import { jsonCodec, binaryCodec } from "@anchor-presence/core";
```

`jsonCodec` is the default codec. `binaryCodec` is a compact fixed-layout binary codec. See [Codecs](/docs/core/codecs) for choosing between them, and [Binary codec](/docs/core/binary-codec) for the wire layout.
