`CursorLayer` draws the cursor of every peer that is visible on your screen. If an arrow with a name label is enough, use it. For a different rendering model, read the positions with [useRemoteCursors](/docs/react/remote-cursors) and draw them yourself.

## Usage

This app connects to the Bun relay of the [Quick start](/docs/get-started/quick-start#connect-a-relay), on port 8788. It renders the remote cursors with the defaults:

```tsx
import { createPresenceClient } from "@anchor-presence/core";
import { createWebSocketTransport } from "@anchor-presence/dom";
import { CursorLayer, LiveCursorProvider } from "@anchor-presence/react";

function App() {
  return (
    <LiveCursorProvider
      factory={() =>
        createPresenceClient({ transport: createWebSocketTransport({ port: 8788, path: "/?room=main" }) })
      }
    >
      <Dashboard />
      <CursorLayer />
    </LiveCursorProvider>
  );
}
```

## Defaults

- **Element:** one fixed-position root element per visible cursor, with `DefaultCursor` inside it.
- **Label:** the `name` field of the peer's `user` value, if it is a string that is not empty. The layer cuts the name to 32 characters (code points). Otherwise, the cursor has no label.
- **Color:** one of 8 palette colors, picked from the peer's `clientId`. A peer keeps its color on every screen. With the default `clientId`, a page reload creates a new one, so the color can change.
- **Stacking:** `zIndex` `9999`, above most app UI.

## Label and color

`getLabel` and `getColor` run for each visible cursor. They replace the default label and the default color. The samples on this page pass inline callbacks for brevity. See [Keep the callbacks stable](#keep-the-callbacks-stable):

```tsx
type MyUser = { name: string; color?: string };

const safeColor = (color?: string) =>
  color !== undefined && /^#[0-9a-f]{6}$/iu.test(color) ? color : "#6b7280";

<CursorLayer<unknown, MyUser>
  getLabel={(cursor) => cursor.user?.name ?? "Guest"}
  getColor={(cursor) => safeColor(cursor.user?.color)}
/>;
```

<Callout type="warn">
  If you render remote `user` data, treat it as text, never as HTML. Another client sends this data, and it
  can hold any value. Check a remote color or URL against an allowlist before you use it. See
  [Security](/docs/get-started/guides/security).
</Callout>

## Filter cursors

`filterCursor` hides a cursor when it returns `false`. It runs after the visibility check, so a hidden cursor never reaches `getLabel` or `getColor`:

```tsx
<CursorLayer filterCursor={(cursor) => cursor.tier !== "viewport"} />
```

## Extra props on the root

`getCursorProps` adds classes, styles, and attributes to the root element of each cursor:

```tsx
<CursorLayer
  getCursorProps={() => ({
    className: "my-cursor",
    "data-testid": "remote-cursor",
  })}
/>
```

`CursorLayer` applies `position`, `left`, `top`, `transform`, `pointerEvents`, and `opacity` after your style, so your values for these keys have no effect. The `zIndex` prop wins over a `zIndex` in your style. A style `zIndex` replaces only the default `9999`. A `transition` in your style wins. If your style has no `transition` and the operating system does not prefer reduced motion, the layer adds `opacity 200ms ease-out`.

## Keep the callbacks stable

`CursorLayer` skips the render of a cursor whose resolved values did not change. This works only while `getLabel`, `getColor`, `getCursorProps`, and `renderCursor` keep their identity. If you pass inline functions and the parent rerenders, every cursor renders again. Declare the callbacks at module level, or wrap them in `useCallback`.

## Dialogs and transforms

<Callout type="warn">
  If a dialog opens with `<dialog>.showModal()`, or an element uses `popover`, it covers the cursors. The
  browser renders these elements in the top layer, above every `z-index`. Render a second `CursorLayer` inside
  the dialog or the popover.
</Callout>

<Callout type="warn">
  If an ancestor of `CursorLayer` has a `transform`, `filter`, or `contain` style, the cursors move to wrong
  positions. These styles change the box that `position: fixed` refers to. Render `CursorLayer` at the root of
  the app.
</Callout>

## Accessibility

- Each cursor root has `aria-hidden="true"` and `pointerEvents: "none"`. Screen readers and pointer input skip it.
- If the operating system prefers reduced motion, `CursorLayer` adds no opacity transition to the root. A `transition` in your style stays. For the movement itself, see [Motion](/docs/dom/motion).
- `DefaultCursor` sets `forced-color-adjust: none`. Its arrow and label keep their colors in Windows forced-colors mode.
- You control the label contrast. `getLabel`, `getColor`, and `renderCursor` set the content and the colors.
