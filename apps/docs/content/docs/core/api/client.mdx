## createPresenceClient

```ts
import { createPresenceClient } from "@anchor-presence/core";
```

`createPresenceClient(options)` builds a `PresenceClient`. See [Presence client](/docs/core/presence-client) for the lifecycle, the publish rate, and the heartbeat.

## Constants

```ts
import { DEFAULT_PUBLISH_INTERVAL_MS, DEFAULT_HEARTBEAT_MS } from "@anchor-presence/core";
```

`DEFAULT_PUBLISH_INTERVAL_MS` is `50`, the default publish interval in milliseconds. `DEFAULT_HEARTBEAT_MS` is `10000`, the default heartbeat interval in milliseconds.
