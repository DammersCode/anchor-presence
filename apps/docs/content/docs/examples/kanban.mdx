When the pane shrinks, this layout keeps every card and column at the same size and position. The board scrolls instead of squishing the columns. In this demo, both panes show the same five-column board. On a wide screen, the wide pane fits three columns and the narrow pane shows two. The board scrolls to the rest.

Both panes render the same markup. Each column is `w-36` and `flex-none`, so a column never squishes. The board row is `overflow-x-auto`.

## Behavior notes

Try it: Select the colored button at the board edge to scroll the card into view.

- The columns keep a fixed width in both panes. The board row is a horizontal scroll container.
- The `+` button in a column header and the `X` button on a card mark the places of the actions. They carry anchors, but they do nothing in this demo.
- The tour points at a card in the third column. The narrow pane hides that card. A colored button at the board edge shows where the cursor is.
- Columns and cards have the same size and position in both panes. A cursor on a visible card moves the same distance in both panes.
