Anchor Presence is a live-cursor library for web apps. It shows where your teammates point and click. It keeps each cursor on the correct element, even when the two screens show different layouts. Use it when users of one page work at the same time on different screen sizes, sidebar states, or zoom levels.

## A minimal example

Mark an element as an anchor, and render the cursor layer inside the provider:

```tsx
<LiveCursorProvider factory={createClient}>
  <button data-anchor="nav.dashboard">Dashboard</button>
  <CursorLayer />
</LiveCursorProvider>
```

[Quick start](/docs/get-started/quick-start) shows the full file, with the `createClient` function.

## The problem

A typical remote cursor is a screen coordinate. Two clients rarely show the same layout. A sidebar can be open on one screen and collapsed on the other. A table can wrap to one column on a narrow screen. On the other screen, a pixel coordinate can land on the wrong element, or on no element.

## The fix

Anchor Presence sends an element ID and a point inside that element, not a screen coordinate. These terms appear in all pages of the docs:

- An **anchor** is an element with a `data-anchor` attribute, for example `<button data-anchor="nav.dashboard">`. The attribute value is the **anchor ID**.
- The **position** is a point inside the anchor, as a fraction from 0 to 1 of its width (`u`) and of its height (`v`).
- The **receiver** is the browser that shows a remote cursor. The receiver measures its own copy of the anchor and turns the position into pixels.
- The **fallback chain** is the anchor, then its parent anchors, then a position in the browser window. If the receiver has no element for an entry, it tries the next entry.
- A **peer** is another client in the same room.
- A **relay** is a server that forwards each message to every other client in a room.

## Packages

The library has three packages. Each package adds one layer. `@anchor-presence/react` depends on `@anchor-presence/dom`, and `@anchor-presence/dom` depends on `@anchor-presence/core`.
