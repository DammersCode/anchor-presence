Install the packages before you write any code. A React app needs all three packages. An app without React needs fewer.

## Install

<Callout type="warn">
  If the install command returns a 404, the packages are not published to npm. Build them from the repository,
  then install them from their folders. The `react` and `dom` packages depend on the other packages by
  version, so your app needs an `overrides` block that points those names to the folders.
</Callout>

Build the packages in a clone of the repository:

```sh
bun install && bun run build
```

Then add an `overrides` block to the `package.json` of your app. Use the real path of your clone:

```json
{
  "overrides": {
    "@anchor-presence/core": "file:../anchor-presence/packages/core",
    "@anchor-presence/dom": "file:../anchor-presence/packages/dom"
  }
}
```

Last, add the packages from the same folders:

```sh
bun add file:../anchor-presence/packages/core file:../anchor-presence/packages/dom file:../anchor-presence/packages/react
```

Pick the tab that matches your app. Each tab installs only the packages that the app uses:

## Requirements

| Requirement   | Version                                                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| React         | 18 or later, only for `@anchor-presence/react`                                                                                 |
| TypeScript    | 5.9 or later                                                                                                                   |
| Browser       | Chrome, Edge, Firefox, and Safari with ES2022 support                                                                          |
| Module format | ESM only. `require()` works in Node.js 20.19 or later on the 20.x line, or 22.12 or later. Jest needs ESM mode or a transform. |

## A transport

A **transport** is the channel that carries the bytes between clients. The library needs one. `@anchor-presence/dom` ships two transports:

- `createBroadcastChannelTransport` connects the tabs of one browser, with no server.
- `createWebSocketTransport` connects any two browsers through a relay.

To use Socket.IO, SignalR, or another library, write a small transport. See [Transports](/docs/core/transports) for the interface.
