`@anchor-presence/core` exports every name below.

## createPresenceClient

Import `createPresenceClient` from `@anchor-presence/core`:

```ts
import { createPresenceClient } from "@anchor-presence/core";
```

`createPresenceClient(options)` builds a `PresenceClient`. See [Presence client](/docs/core/presence-client) for the lifecycle, the publish rate, and the heartbeat.

## Constants

Import the client and store constants from `@anchor-presence/core`:

```ts
import {
  DEFAULT_PUBLISH_INTERVAL_MS,
  DEFAULT_HEARTBEAT_MS,
  DEFAULT_STALE_TIMEOUT_MS,
  DEFAULT_IDLE_AFTER_MS,
  DEFAULT_MAX_REMOTE_CLIENTS,
} from "@anchor-presence/core";
```

| Constant                      | Value   | Default for                       |
| ----------------------------- | ------- | --------------------------------- |
| `DEFAULT_PUBLISH_INTERVAL_MS` | `50`    | `publishIntervalMs`, milliseconds |
| `DEFAULT_HEARTBEAT_MS`        | `10000` | `heartbeatMs`, milliseconds       |
| `DEFAULT_STALE_TIMEOUT_MS`    | `70000` | `staleTimeoutMs`, milliseconds    |
| `DEFAULT_IDLE_AFTER_MS`       | `15000` | `idleAfterMs`, milliseconds       |
| `DEFAULT_MAX_REMOTE_CLIENTS`  | `64`    | `maxRemoteClients`                |
