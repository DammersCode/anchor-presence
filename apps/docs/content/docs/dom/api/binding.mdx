This page lists `createDomBinding` and its option types. Use it to look up a field. The [Binding](/docs/dom/binding) guide explains the behavior. Import them from the package:

```ts
import { createDomBinding } from "@anchor-presence/dom";
import type { DomBinding, DomBindingOptions } from "@anchor-presence/dom";
```

## createDomBinding

`createDomBinding(client, options?)` creates the DOM side of one client and returns a `DomBinding`. It throws a `TypeError` for a bad `anchorAttribute` or a `maxAnchors` that is not an integer. See [Options](/docs/dom/binding#options).

## Host types

`@anchor-presence/dom` exports the types of the `environment` fields. A fake host for a test must fit these shapes:

```ts
type RafLike = (callback: (timestampMs: number) => void) => number;
type CafLike = (handle: number) => void;

type ResizeObserverLike = {
  observe(target: Element): void;
  unobserve(target: Element): void;
  disconnect(): void;
};
type ResizeObserverCtor = new (callback: () => void) => ResizeObserverLike;

type MutationObserverLike = {
  observe(target: Node, options: MutationObserverInit): void;
  unobserve?(target: Node): void;
  disconnect(): void;
};
type MutationObserverCtor = new (callback: (records?: MutationRecord[]) => void) => MutationObserverLike;
```

The browser `requestAnimationFrame`, `cancelAnimationFrame`, `ResizeObserver`, and `MutationObserver` fit these types.
