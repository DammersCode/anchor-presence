## LiveCursorContext

`LiveCursorContext` is the React context that `LiveCursorProvider` fills. Import it and its value type from `@anchor-presence/react`:

```ts
import { LiveCursorContext, type LiveCursorContextValue } from "@anchor-presence/react";
```

<AutoTypeTable path="../../packages/react/src/context.ts" name="LiveCursorContextValue" />

Outside a provider, both fields are `null`. During server rendering, `binding` is `null`. The hooks read this context for you. To get the `DomBinding`, call [`useCursorBinding`](/docs/react/api/hooks#usecursorbinding).

This component reads the context directly and shows a line when the client and the binding exist:

```tsx
import { useContext } from "react";
import { LiveCursorContext } from "@anchor-presence/react";

function PresenceReady() {
  const { client, binding } = useContext(LiveCursorContext);
  return client !== null && binding !== null ? <p>Presence is ready.</p> : null;
}
```
