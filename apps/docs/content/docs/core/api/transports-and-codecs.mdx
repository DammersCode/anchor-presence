This page lists the transport and codec exports of `@anchor-presence/core` with their types. Use it to look up a member. The guides explain the behavior.

```ts
import { binaryCodec, createInMemoryPair, jsonCodec } from "@anchor-presence/core";
import type { CursorCodec, LiveCursorTransport, TransportClose } from "@anchor-presence/core";
```

## LiveCursorTransport

`LiveCursorTransport` is the interface that every transport implements. See [Transports](/docs/core/transports) for the contract.

## TransportClose

`TransportClose` is the value that a transport gives to its `subscribeClose` listeners when a connection closes. See [Close reasons](/docs/core/transports#close-reasons).

## createInMemoryPair

`createInMemoryPair(options?)` returns two transports wired to each other. See [In-memory transport](/docs/core/in-memory-transport).

<AutoTypeTable path="../../packages/core/src/in-memory-transport.ts" name="InMemoryPairOptions" />

`InMemoryTransport` is the type of `a` and `b`. It is a `LiveCursorTransport` that always has `connect`, `disconnect`, `subscribeStatus`, and `getStatus`.

## CursorCodec

`CursorCodec` is the interface that every codec implements. See [Codecs](/docs/core/codecs#cursorcodec) for the rules.

<AutoTypeTable path="../../packages/core/src/codec.ts" name="CursorCodec" />

## jsonCodec and binaryCodec

`jsonCodec` is the default codec. `binaryCodec` is a compact codec with a fixed binary layout. Both codecs carry leave messages and events. See [Choose a codec](/docs/core/codecs#choose-a-codec) and the [binary wire layout](/docs/core/binary-codec#wire-layout).
