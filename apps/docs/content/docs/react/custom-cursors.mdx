`CursorLayer` places one root element per remote cursor. `renderCursor` replaces what that root shows, and `DefaultCursor` is the arrow that it shows by default. Use them to change the look of a cursor. The position always stays with `CursorLayer`.

## Usage

`renderCursor` replaces only the content of the root. The samples on this page pass `renderCursor` inline for brevity. Declare it at module level, as in [Keep the callbacks stable](/docs/react/cursor-layer#keep-the-callbacks-stable):

```tsx
import type { ReactNode } from "react";
import { CursorLayer } from "@anchor-presence/react";

function MyCursorGlyph({ color, children }: { color: string; children: ReactNode }) {
  return <span data-color={color}>{children}</span>;
}

function GlyphLayer() {
  return (
    <CursorLayer
      renderCursor={({ label, color }) => (
        <MyCursorGlyph color={color}>
          <span>{label}</span>
        </MyCursorGlyph>
      )}
    />
  );
}
```

`renderCursor` receives the resolved `cursor`, the `label` from `getLabel`, and the `color` from `getColor`. `CursorLayer` keeps control of the root position, transform, pointer events, `aria-hidden`, and data attributes.

## Style DefaultCursor

`DefaultCursor` needs no Tailwind and no external stylesheet. Three CSS variables control its look: `--anchor-presence-cursor-color`, `--anchor-presence-cursor-size`, and `--anchor-presence-cursor-label-color`. This renderer makes the arrow larger:

```tsx
import { CursorLayer, DefaultCursor } from "@anchor-presence/react";

function LargeCursorLayer() {
  return (
    <CursorLayer
      renderCursor={({ label, color }) => (
        <DefaultCursor label={label} color={color} style={{ "--anchor-presence-cursor-size": "28px" }} />
      )}
    />
  );
}
```

The `--anchor-presence-cursor-color` variable on `style` wins over the `color` prop. A `label` of `null` or `undefined` shows the arrow without a label. For every prop, see [DefaultCursor](/docs/react/api/components#defaultcursor).

## Root attributes

The root of each cursor carries these attributes. Select and test cursors with them, not with class names:

| Attribute                        | Value                                                                                                                       |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `data-anchor-presence-cursor`    | present on every cursor root                                                                                                |
| `data-anchor-presence-client-id` | the `clientId` of the peer                                                                                                  |
| `data-anchor-presence-tier`      | the resolution tier: `"anchor"` or `"viewport"`. A `visibilityPolicy` that shows a `"hidden"` cursor also gives `"hidden"`. |
| `data-anchor-presence-anchor`    | the anchor ID that resolved the cursor, or `""`                                                                             |
| `data-anchor-presence-idle`      | present while the peer is idle                                                                                              |

## Idle cursors

A peer is idle when its presence does not change for `idleAfterMs`. See [Idle state](/docs/core/remote-presence#idle-state). `CursorLayer` sets the opacity of an idle cursor to `0.4` and adds `data-anchor-presence-idle`. Use the attribute for your own idle style:

```css
[data-anchor-presence-idle] {
  filter: grayscale(1);
}
```

To show the idle state next to a name in a list, use [Remote users](/docs/react/remote-users).
