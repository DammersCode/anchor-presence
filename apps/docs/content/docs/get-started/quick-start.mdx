Run live cursors in two steps. First, connect two tabs of one browser with no backend. Then connect two browsers through a relay. A relay is a server that forwards each message to every other client in a room.

## Try it in two tabs

`createBroadcastChannelTransport` from `@anchor-presence/dom` connects the tabs and iframes of one origin, with no server. Pass the provider a `factory` that creates the transport and the client. Mark one element with `data-anchor`:

```tsx
import { createPresenceClient } from "@anchor-presence/core";
import { createBroadcastChannelTransport } from "@anchor-presence/dom";
import { CursorLayer, LiveCursorProvider } from "@anchor-presence/react";

function createClient() {
  const transport = createBroadcastChannelTransport("live-cursors");
  return createPresenceClient({ transport, user: { name: `Guest ${Math.floor(Math.random() * 100)}` } });
}

export function App() {
  return (
    <LiveCursorProvider factory={createClient}>
      <button data-anchor="nav.dashboard">Dashboard</button>
      <CursorLayer />
    </LiveCursorProvider>
  );
}
```

Open your app in two tabs of the same browser. Move the pointer in one tab. A cursor with a guest name appears in the other tab. `CursorLayer` shows `user.name` as the label. It gives each client one color from a palette of 8 colors.

The provider runs the factory once per mount, in a browser-only effect, and disposes the client on unmount. Create the client in the factory, not at module scope. A module-scope client also runs on the server, and every request then shares it. See [SSR and Strict Mode](/docs/react/ssr-and-strict-mode).

## Connect a relay

A `BroadcastChannel` never leaves the browser. To connect two browsers or two devices, run a relay and use `createWebSocketTransport`. Start the [Bun relay](/docs/examples/backends/bun-native) from a clone of the repository:

```sh
bun install
cd examples/bun-native
bun run dev:relay
```

The relay listens on port 8788. Change only the transport in `createClient`:

```tsx
import { createPresenceClient } from "@anchor-presence/core";
import { createWebSocketTransport } from "@anchor-presence/dom";

function createClient() {
  const transport = createWebSocketTransport({ port: 8788, path: "/?room=main" });
  return createPresenceClient({ transport, user: { name: `Guest ${Math.floor(Math.random() * 100)}` } });
}
```

The client connects the transport by default. `room` is a key of the relay that groups clients, not part of the protocol. Every relay in [Backends](/docs/examples/backends) uses its own port, so set `port` to the port of the relay that you run. Any bidirectional byte channel that implements the transport interface works in place of `createWebSocketTransport`. See [Transports](/docs/core/transports).

## Without React

`@anchor-presence/core` and `@anchor-presence/dom` work with no React in the tree. Subscribe to the resolved cursors of the binding, and render them yourself with plain DOM updates or another framework. See [Binding](/docs/dom/binding) for the subscribe method. To connect the binding to the reactivity of a framework, see [Build a framework adapter](/docs/core/build-a-framework-adapter).
