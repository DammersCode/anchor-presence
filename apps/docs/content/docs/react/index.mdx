title: Overview

`@anchor-presence/react` adapts a presence client to React. It provides one provider that creates and shares the client, and two optional components to render cursors. It holds no state of its own. Every hook subscribes to the `@anchor-presence/core` client and the `@anchor-presence/dom` binding with `useSyncExternalStore`.

## What you get

A peer is another client in the same room. The package gives you these exports:

| Export                                                   | Purpose                                                                                         |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| [`LiveCursorProvider`](/docs/react/live-cursor-provider) | creates the client through `factory` and shares it with its DOM binding                         |
| [`CursorLayer`](/docs/react/cursor-layer)                | renders every visible remote cursor                                                             |
| Hooks under [Hooks](/docs/react/remote-cursors)          | read cursors, users, peer changes, context, the local user, status, the client, and the binding |
| [`useCursorEvents`](/docs/react/cursor-events)           | receives one-shot events from peers                                                             |
| [`createPresenceHooks`](/docs/react/typed-hooks)         | returns the provider and the hooks with your types fixed                                        |

## Minimal setup

This example connects to a WebSocket relay and renders remote cursors:

```tsx
import { createPresenceClient } from "@anchor-presence/core";
import { createWebSocketTransport } from "@anchor-presence/dom";
import { CursorLayer, LiveCursorProvider } from "@anchor-presence/react";

function App() {
  return (
    <LiveCursorProvider
      factory={() => {
        const transport = createWebSocketTransport({ path: "/?room=main" });
        return createPresenceClient({ transport });
      }}
    >
      <Dashboard />
      <CursorLayer />
    </LiveCursorProvider>
  );
}
```

Before the factory runs, the provider renders its children with no cursors. The tree stays safe during that gap and during server rendering. For when the factory runs, see [Create the client](/docs/react/client-creation). See [Quick start](/docs/get-started/quick-start) for the full walkthrough, including the anchor markup.
