This page lists the client exports of `@anchor-presence/core` with their types. Use it to look up an option or a method. The guides explain the behavior. Import them from the package:

```ts
import { createPresenceClient } from "@anchor-presence/core";
```

## createPresenceClient

`createPresenceClient(options)` builds a `PresenceClient`. See [Presence client](/docs/core/presence-client).

It throws a `TypeError` in these cases:

- `transport` is missing.
- `clientId` is not a string of 1 to 128 characters. The limit is `validationLimits.maxClientIdLength` when you set it.
- The session ID that `idFactory` returns is not a string of 1 to 64 characters.
- One of these options is not a finite number:

  - `publishIntervalMs`, `heartbeatIntervalMs`, `staleTimeoutMs`, and `idleAfterMs`.
  - `maxRemoteClients`.
  - `adaptivePublish.highWatermarkBytes`, `adaptivePublish.lowWatermarkBytes`, and `adaptivePublish.slowPublishIntervalMs`.

The fields of `eventRateLimit` and `validationLimits` get no such check.

## createEventChannel

`createEventChannel` and its types have these signatures:

```ts
type EventMap = Record<string, unknown>;

type TypedRemoteEvent<TEvents extends object> = {
  [K in keyof TEvents & string]: { clientId: string; type: K; data: TEvents[K] };
}[keyof TEvents & string];

type EventChannel<TEvents extends object> = {
  send<K extends keyof TEvents & string>(
    type: K,
    ...data: undefined extends TEvents[K] ? [data?: TEvents[K]] : [data: TEvents[K]]
  ): boolean;
  subscribe(listener: (event: TypedRemoteEvent<TEvents>) => void): () => void;
};

function createEventChannel<TEvents extends object>(
  client: Pick<PresenceClient, "sendEvent" | "subscribeEvents">,
): EventChannel<TEvents>;
```

An `EventMap` maps each event type to the type of its `data`. The functions accept any object type, so an `interface` works as well as a `type`. `TypedRemoteEvent<TEvents>` is a union with one member for each event type. The channel does not check remote data. See [Typed events](/docs/core/events#typed-events).

## createEventParser

`createEventParser` and `EventParsers` have these signatures:

```ts
type EventParsers<TEvents extends object> = {
  [K in keyof TEvents & string]:
    ((data: unknown) => TEvents[K] | undefined) | (undefined extends TEvents[K] ? null : never);
};

function createEventParser<TEvents extends object>(
  parsers: EventParsers<TEvents>,
): (event: RemoteEvent) => TypedRemoteEvent<TEvents> | undefined;
```

`createEventParser` returns a function for the `parseEvent` option. `null` is legal only for an event whose data type includes `undefined`. The returned function drops an event in these cases:

- `parsers` has no entry for its `type`.
- Its parser returns `undefined`.
- Its entry is `null` and the event carries data.

See [Typed events](/docs/core/events#typed-events) for a sample.

## Interpolators

`linearInterpolator(durationMs?)` returns an `Interpolator` with a linear ease. `durationMs` defaults to `80`. `noneInterpolator` is an `InterpolatorFactory` whose interpolator jumps to each target. See [Interpolation](/docs/core/interpolation) for the rules and a custom interpolator.

## isDevMode

`isDevMode()` returns whether the code runs in development mode. See [Development mode](/docs/core/presence-client#development-mode) for the rules.

## warnOnce

`warnOnce(key, message)` writes `[anchor-presence] <message>` with `console.warn`. It writes only in development mode, and only one time for each `key` in the page or process. The packages use it for their own warnings. A key that you pass shares this set with the keys of the packages.

## reportListenerError

`reportListenerError(error)` writes `error` with `console.error` in development mode, and does nothing in production. The packages call it when a listener of your code throws, so that one listener cannot stop the others.

## Constants

Import the client and store constants from `@anchor-presence/core`:

```ts
import {
  DEFAULT_PUBLISH_INTERVAL_MS,
  DEFAULT_HEARTBEAT_INTERVAL_MS,
  DEFAULT_STALE_TIMEOUT_MS,
  DEFAULT_IDLE_AFTER_MS,
  DEFAULT_MAX_REMOTE_CLIENTS,
} from "@anchor-presence/core";
```

| Constant                        | Value   | Default for                         |
| ------------------------------- | ------- | ----------------------------------- |
| `DEFAULT_PUBLISH_INTERVAL_MS`   | `50`    | `publishIntervalMs`, milliseconds   |
| `DEFAULT_HEARTBEAT_INTERVAL_MS` | `10000` | `heartbeatIntervalMs`, milliseconds |
| `DEFAULT_STALE_TIMEOUT_MS`      | `70000` | `staleTimeoutMs`, milliseconds      |
| `DEFAULT_IDLE_AFTER_MS`         | `15000` | `idleAfterMs`, milliseconds         |
| `DEFAULT_MAX_REMOTE_CLIENTS`    | `64`    | `maxRemoteClients`                  |
