`@anchor-presence/react` exports the hooks below, with these signatures and return types. See the page of each hook for prose, render cost, and examples.

## useRemoteCursors

`useRemoteCursors` has this signature:

```ts
function useRemoteCursors<TContext = unknown, TUser = unknown>(): ResolvedCursor<TContext, TUser>[];
```

See [Remote cursors](/docs/react/remote-cursors).

## useRemoteCursorsSelector

`useRemoteCursorsSelector` has this signature, and `isEqual` defaults to `Object.is`:

```ts
function useRemoteCursorsSelector<TSelected, TContext = unknown, TUser = unknown>(
  select: (cursors: ResolvedCursor<TContext, TUser>[]) => TSelected,
  isEqual?: (a: TSelected, b: TSelected) => boolean,
): TSelected;
```

See [Remote cursors](/docs/react/remote-cursors).

## useLocalUser

`useLocalUser` has this signature:

```ts
function useLocalUser<TUser = unknown>(): [TUser | undefined, (next: TUser | undefined) => void];
```

It returns the local `user` value and a setter that calls `client.setUser`. During server rendering, the value is `undefined`. Without a client, the setter does nothing. See [Local user](/docs/react/local-context#local-user).

## useCursorStatus

`useCursorStatus` has this signature:

```ts
function useCursorStatus(): ConnectionStatus;
```

It returns one of `"connecting"`, `"connected"`, `"reconnecting"`, or `"disconnected"`. See [Connection status](/docs/react/connection-status).

## useCursorClient

`useCursorClient` has this signature:

```ts
function useCursorClient<TContext = unknown, TUser = unknown>(): PresenceClient<TContext, TUser> | null;
```

It returns the client of the nearest `LiveCursorProvider`. Outside a provider, it returns `null`. During server rendering, it returns the `client` prop of the provider. A provider with a `factory` and no `client` prop has no client on the server, so the hook returns `null`.

## useCursorBinding

`useCursorBinding` has this signature:

```ts
function useCursorBinding<TContext = unknown, TUser = unknown>(): DomBinding<TContext, TUser> | null;
```

It returns the DOM binding of the nearest `LiveCursorProvider`. Before the provider creates the binding, and outside a provider, it returns `null`. During server rendering, it returns the `binding` prop of the provider, or `null` without that prop. If state that a `visibilityPolicy` reads changes, call `binding.invalidate()`. See [Run the policy again after a state change](/docs/dom/visibility-policy#run-the-policy-again-after-a-state-change).

## useCursorEvents

`useCursorEvents` has this signature:

```ts
function useCursorEvents(listener: (event: RemoteEvent) => void): void;
```

A peer is another client in the same room. `useCursorEvents` calls `listener` for each event that a peer sends with `client.sendEvent`. `RemoteEvent` has a `type`, an optional `data`, and the `clientId` of the sender. See [Cursor events](/docs/react/cursor-events).

## usePeerChanges

`usePeerChanges` has this signature:

```ts
function usePeerChanges<TContext = unknown, TUser = unknown>(
  listener: (change: PeerChange<TContext, TUser>) => void,
): void;
```

It calls `listener` when a peer joins, leaves, or changes its `user` or `context`. `PeerChange` has a `type` of `join`, `update`, or `leave`, the `clientId` of the peer, and its `user` and `context`. See [Peer changes](/docs/react/remote-users#peer-changes).

## useSendEvent

`useSendEvent` exists only in the result of `createPresenceHooks`, so it has your event types. It returns a function with the signature of `EventChannel<TEvents>["send"]`. The function returns `false` without a client. See [Typed events](/docs/react/typed-hooks#typed-events).

## createPresenceHooks

`createPresenceHooks` returns a provider and hooks with your types fixed:

```ts
function createPresenceHooks<TContext = unknown, TUser = unknown, TEvents extends object = EventMap>(): {
  LiveCursorProvider: (props: LiveCursorProviderProps<TContext, TUser>) => ReactNode;
  useCursorBinding: () => DomBinding<TContext, TUser> | null;
  useCursorClient: () => PresenceClient<TContext, TUser> | null;
  useLocalContext: () => [TContext | undefined, (next: TContext | undefined) => void];
  useCursorEvents: (listener: (event: TypedRemoteEvent<TEvents>) => void) => void;
  useRemotePresence: () => RemotePresence<TContext, TUser>[];
  useCursorStatus: () => ConnectionStatus;
  useRemoteCursors: () => ResolvedCursor<TContext, TUser>[];
  useRemoteCursorsSelector: <TSelected>(
    select: (cursors: ResolvedCursor<TContext, TUser>[]) => TSelected,
    isEqual?: (a: TSelected, b: TSelected) => boolean,
  ) => TSelected;
  useRemoteUsers: () => RemoteUser<TUser>[];
  useLocalUser: () => [TUser | undefined, (next: TUser | undefined) => void];
  usePeerChanges: (listener: (change: PeerChange<TContext, TUser>) => void) => void;
  useSendEvent: () => EventChannel<TEvents>["send"];
};
```

`TEvents` is an event map that types the events. The `useCursorEvents` of the result passes a `TypedRemoteEvent<TEvents>` to the listener. The result also has [`useSendEvent`](#usesendevent). See [Typed hooks](/docs/react/typed-hooks).
