Anchor Presence is a live-cursor layer for web apps. It shows where your teammates are looking and clicking. It keeps every cursor on the correct element, even when their layout, sidebar, or screen size differs from yours.

## The problem

A remote cursor is usually a screen coordinate. Two clients rarely show the same layout: a sidebar can be collapsed on one screen and open on another, and a table can wrap to one column on a narrow screen. A pixel coordinate from one screen can land on the wrong element, or on no element at all, on another screen.

## The fix

Anchor Presence never sends a screen coordinate as the primary signal. It sends a semantic anchor ID plus a normalized position inside that anchor. Each receiver measures its own copy of the anchor and computes a pixel position from that proportion. Read [Anchors](/docs/get-started/concepts/anchors) and [Fallback chain](/docs/get-started/concepts/fallback-chain) for the full model.

## Packages

The library has three packages. Each adds one layer, and the dependency direction is one-way: `@anchor-presence/react` depends on `@anchor-presence/dom`, and `@anchor-presence/dom` depends on `@anchor-presence/core`.

| Package                  | What it does                                                    | Depends on DOM or React |
| ------------------------ | --------------------------------------------------------------- | ----------------------- |
| `@anchor-presence/core`  | Protocol, validation, presence store, client orchestration.     | No                      |
| `@anchor-presence/dom`   | Anchor registry, pointer capture, geometry scheduler, resolver. | DOM only                |
| `@anchor-presence/react` | Provider component and hooks, built on `useSyncExternalStore`.  | React                   |

## Guarantees

The library holds a fixed set of rules on every message: layout independence, predictable degradation, and no engine state outside `@anchor-presence/core`. See [How it works](/docs/get-started/concepts/how-it-works) for the full list of invariants.
