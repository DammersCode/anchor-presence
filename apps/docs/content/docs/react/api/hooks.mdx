This page lists the signature of every hook in `@dammers/anchor-presence-react`, and of `createPresenceHooks`. Use it to look up a type. For usage, render cost, and examples, read the guide page that each section links to.

Every hook reads the nearest `PresenceProvider`. A hook that you import from `@dammers/anchor-presence-react` takes no type argument and returns `unknown` for `user`, `context`, and event `data`. A type argument cannot prove what a peer sends. To get typed values, call [`createPresenceHooks`](#createpresencehooks) and use its hooks. Without a provider, each hook returns its empty value, and in development mode one console warning appears. For the empty values, see [Server-safe values](/docs/react/ssr-and-strict-mode#server-safe-values).

## useRemoteCursors

```ts
function useRemoteCursors(): readonly ResolvedCursor[];
```

Returns the resolved cursor of every peer, hidden cursors included. While the client reconnects or is disconnected, the list is empty. Guide: [Remote cursors](/docs/react/remote-cursors).

## useRemoteCursorsSelector

```ts
function useRemoteCursorsSelector<TSelected>(
  select: (cursors: readonly ResolvedCursor[]) => TSelected,
  isEqual?: (a: TSelected, b: TSelected) => boolean,
): TSelected;
```

Returns `select` applied to the resolved cursors. `isEqual` defaults to `Object.is`. Guide: [Select a smaller value](/docs/react/remote-cursors#select-a-smaller-value).

## useRemoteUsers

```ts
function useRemoteUsers(): readonly RemoteUser[];
```

Returns one `RemoteUser` per peer. For its fields, see [RemoteUser fields](/docs/react/remote-users#remoteuser-fields).

Guide: [Remote users](/docs/react/remote-users).

## useRemotePresence

```ts
function useRemotePresence(): readonly RemotePresence[];
```

Returns the raw presence of every peer, in the coordinates of the sender. Guide: [Raw presence](/docs/react/remote-presence).

## useLocalUser

```ts
function useLocalUser(): [unknown, (next: unknown) => void];
```

Returns the local `user` value and a setter that calls `client.setUser`. Guide: [Local user](/docs/react/local-context#local-user).

## useLocalContext

```ts
function useLocalContext(): [unknown, (next: unknown) => void];
```

Returns the local context value and a setter that calls `client.setContext`. Guide: [Local context](/docs/react/local-context#local-context).

## usePresenceStatus

```ts
function usePresenceStatus(): ConnectionStatus;
```

Returns `"connecting"`, `"connected"`, `"reconnecting"`, or `"disconnected"`. Guide: [Connection status](/docs/react/connection-status).

## usePresenceClient

```ts
function usePresenceClient(): PresenceClient | null;
```

Returns the client of the nearest provider, or `null` without one. On the server, it returns the `client` prop of the provider. A provider with only a `factory` has no client on the server, so the hook returns `null`. Guide: [Create the client](/docs/react/client-creation).

## useDomBinding

```ts
function useDomBinding(): DomBinding | null;
```

Returns the DOM binding of the nearest provider. It returns `null` before the provider creates the binding, and without a provider. On the server, it returns the `binding` prop of the provider, or `null` without that prop.

If state that a `visibilityPolicy` reads changes, call `binding.invalidate()`. See [Run the policy again after a state change](/docs/dom/visibility-policy#run-the-policy-again-after-a-state-change).

## useRemoteEvents

```ts
function useRemoteEvents(listener: (event: TypedRemoteEvent<EventMap>) => void): void;
```

Calls `listener` for each event that a peer sends with `client.sendEvent`. The event has a `type`, a `data` of the type `unknown`, and the `clientId` of the sender. Guide: [Remote events](/docs/react/remote-events).

## usePeerChanges

```ts
function usePeerChanges(listener: (change: PeerChange) => void): void;
```

Calls `listener` when a peer joins, leaves, or changes its `user` or `context`. Guide: [Peer changes](/docs/react/remote-users#peer-changes).

## useSendEvent

```ts
function useSendEvent(): EventChannel<EventMap>["send"];
```

Returns a function that sends one event to every peer. The function returns the result of `client.sendEvent`. Without a client, it sends nothing and returns `false`.

The function accepts any `type` and any `data`. The `useSendEvent` of the `createPresenceHooks` result accepts only the events of its event map `TEvents`. Guides: [Remote events](/docs/react/remote-events#send-typed-events) and [Typed events](/docs/react/typed-hooks#typed-events).

## createPresenceHooks

`createPresenceHooks` returns a provider, the hooks, and a `CursorLayer` with your types fixed. The hooks read only the provider of the same call:

```ts
function createPresenceHooks<TContext = unknown, TUser = unknown, TEvents extends object = EventMap>(): {
  PresenceProvider: (props: PresenceProviderProps<TContext, TUser, TEvents>) => ReactNode;
  CursorLayer: (props: CursorLayerProps<TContext, TUser>) => ReactNode;
  useDomBinding: () => DomBinding<TContext, TUser> | null;
  usePresenceClient: () => PresenceClient<TContext, TUser, TEvents> | null;
  useLocalContext: () => [TContext | undefined, (next: TContext | undefined) => void];
  useRemoteEvents: (listener: (event: TypedRemoteEvent<TEvents>) => void) => void;
  useRemotePresence: () => readonly RemotePresence<TContext, TUser>[];
  usePresenceStatus: () => ConnectionStatus;
  useRemoteCursors: () => readonly ResolvedCursor<TContext, TUser>[];
  useRemoteCursorsSelector: <TSelected>(
    select: (cursors: readonly ResolvedCursor<TContext, TUser>[]) => TSelected,
    isEqual?: (a: TSelected, b: TSelected) => boolean,
  ) => TSelected;
  useRemoteUsers: () => readonly RemoteUser<TUser>[];
  useLocalUser: () => [TUser | undefined, (next: TUser | undefined) => void];
  usePeerChanges: (listener: (change: PeerChange<TContext, TUser>) => void) => void;
  useSendEvent: () => EventChannel<TEvents>["send"];
};
```

`TEvents` is an event map. The `useRemoteEvents` of the result passes a `TypedRemoteEvent<TEvents>` to the listener. Guide: [Typed hooks](/docs/react/typed-hooks).

## Re-exported types

The package re-exports the types that its signatures use, so you can import them from `@dammers/anchor-presence-react`:

- From `@dammers/anchor-presence-core`: `AnchorPoint`, `ConnectionStatus`, `CursorPosition`, `PresenceMessage`, `EventChannel`, `EventMap`, `Interpolator`, `InterpolatorFactory`, `PeerChange`, `PointerType`, `PresenceClient`, `PresenceEvent`, `RemoteEvent`, `RemotePresence`, and `TypedRemoteEvent`. See the [protocol types](/docs/core/api/protocol) and the [client API](/docs/core/api/client).
- From `@dammers/anchor-presence-dom`: `DomBinding`, `DomBindingOptions`, `ResolutionTier`, and `ResolvedCursor`. See the [binding API](/docs/dom/api/binding) and the [resolution API](/docs/dom/api/resolution).
