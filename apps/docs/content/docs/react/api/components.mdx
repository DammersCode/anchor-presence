## PresenceProvider

Import `PresenceProvider` from `@anchor-presence/react`:

```ts
import { PresenceProvider } from "@anchor-presence/react";
```

<AutoTypeTable path="../../packages/react/src/provider.tsx" name="PresenceProviderProps" />

Pass exactly one of `client` and `factory`.

`PresenceProviderProps` is `PresenceProviderConfig & { children }`. Use `PresenceProviderConfig`, the props without `children`, to type a wrapper that forwards its props to the provider.

This provider takes only an untyped client, and the hooks that you import from `@anchor-presence/react` return `unknown`. A typed client goes to the `PresenceProvider` of a [`createPresenceHooks`](/docs/react/typed-hooks) result.

Guide: [PresenceProvider](/docs/react/presence-provider). For `bindingKey`, see [Rebuild the binding](/docs/react/presence-provider#rebuild-the-binding). For `clientKey`, see [Switch rooms](/docs/react/presence-provider#switch-rooms).

## PresenceProviderContext

`PresenceProviderContext` is the React context that `PresenceProvider` fills. Import it and its value type from `@anchor-presence/react`:

```ts
import { PresenceProviderContext, type PresenceProviderValue } from "@anchor-presence/react";
```

<AutoTypeTable path="../../packages/react/src/context.ts" name="PresenceProviderValue" />

`client` is a `PresenceClient` or `null`, and `binding` is a `DomBinding` or `null`. `client` and `binding` are `null` outside a provider. A provider with a `factory` has a `null` client until the factory runs. In that time `clientPending` is `true`. It is `false` with `client={null}`, and absent without a provider. During server rendering, `binding` is the `binding` prop of the provider, or `null` without that prop. The hooks that you import from `@anchor-presence/react` read this context for you, so most apps never read it directly. The provider of a `createPresenceHooks` result fills its own context instead.

This component reads the context directly and shows a line when the client and the binding exist:

```tsx
import { useContext } from "react";
import { PresenceProviderContext } from "@anchor-presence/react";

function PresenceReady() {
  const { client, binding } = useContext(PresenceProviderContext);
  return client !== null && binding !== null ? <p>Presence is ready.</p> : null;
}
```
