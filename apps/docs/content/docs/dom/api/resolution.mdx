## ResolutionTier

`ResolutionTier` is a union of three string values: `"anchor"`, `"viewport"`, `"hidden"`. See [Resolution](/docs/dom/resolution) for what each tier means.

## VisibilityPolicy

A function that decides whether one resolved cursor renders:

<AutoTypeTable path="../../packages/dom/src/resolver.ts" name="VisibilityPolicy" />

`CURSOR_MARKER_ATTRIBUTE`, exported from `@anchor-presence/dom`, is the attribute the binding's own scheduler looks for to skip a renderer's own cursor mutations when watching for layout changes. A renderer that draws cursors sets this attribute on each cursor root; `@anchor-presence/react` does this for you.
