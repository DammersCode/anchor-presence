`useRemotePresence` returns the raw presence of each peer. This is the data that the DOM binding later resolves into cursors. Use it only for a field that a resolved cursor does not carry, such as `session` or the anchor chain of the sender. To draw cursors, use [Remote cursors](/docs/react/remote-cursors). For a list of people, use [Remote users](/docs/react/remote-users).

## Usage

This component counts the peers whose cursor has no anchor, so the receiver can place it only by viewport position:

```tsx
import { useRemotePresence } from "@anchor-presence/react";

function ViewportOnlyBadge() {
  const presence = useRemotePresence();
  const count = presence.filter((p) => p.cursor !== null && p.cursor.anchors.length === 0).length;
  return <span>{count} viewport-only cursors</span>;
}
```

## Entries

Each entry is a [`RemotePresence`](/docs/core/api/protocol#remotepresence): the presence message of the peer without its `sequence` field, plus `idle`. A `user` or `context` of `null` stays `null` here. `useRemoteUsers` turns it into `undefined`.

The hook rerenders only when the `cursor`, `context`, `user`, `pointer`, `session`, or `idle` field of a peer changes, or when a peer joins or leaves. A message that only advances `sequence` does not rerender it.

<Callout type="warn">
  If you place an element on screen with `useRemotePresence`, the element lands in the wrong place. The
  positions are in the coordinates of the sender, not in pixels of your viewport. Use `useRemoteCursors`
  instead.
</Callout>
