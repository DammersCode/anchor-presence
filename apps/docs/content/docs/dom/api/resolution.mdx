This page lists the types of the resolution result. Use it to look up a field. The [Resolution](/docs/dom/resolution) and [Visibility policy](/docs/dom/visibility-policy) guides explain the behavior.

```ts
import type { ResolvedCursor, ResolutionTier, VisibilityPolicy } from "@anchor-presence/dom";
```

## ResolvedCursor

A `ResolvedCursor` is one resolved remote cursor, in the viewport pixels of the receiver.

## ResolutionTier

`ResolutionTier` is `"anchor" | "viewport" | "hidden"`. See [The three tiers](/docs/dom/resolution#the-three-tiers).

## CURSOR_MARKER_ATTRIBUTE

`CURSOR_MARKER_ATTRIBUTE` is the string `"data-anchor-presence-cursor"`. The binding ignores the DOM changes inside an element with this attribute. A renderer sets it on the root element of each cursor. `@anchor-presence/react` sets it for you. See [Draw cursors without React](/docs/dom/binding#draw-cursors-without-react).
