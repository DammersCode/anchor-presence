`useRemoteCursors` returns the list of resolved remote cursors. A resolved cursor is the cursor of a peer (another client in the same room), converted into a position on your screen. Use the hook to build your own cursor renderer instead of [CursorLayer](/docs/react/cursor-layer), or to read cursor positions for another purpose, such as a minimap.

## Usage

The list also contains the hidden cursors. This component counts the visible ones:

```tsx
import { useRemoteCursors } from "@anchor-presence/react";

function CursorCount() {
  const cursors = useRemoteCursors();
  const visibleCount = cursors.filter((cursor) => cursor.visible).length;
  return <span>{visibleCount} cursors visible</span>;
}
```

## ResolvedCursor fields

Each entry has `clientId`, `x`, `y`, `visible`, `pointVisible`, `anchorId`, `tier`, `idle`, and, when the peer sent them, `context` and `user`. For the meaning of each field, see [ResolvedCursor](/docs/dom/api/resolution#resolvedcursor).

`x` and `y` are pixels in your viewport. To place an element at these values, use `position: fixed`. Give the element `pointer-events: none` and `aria-hidden="true"`, so that pointer input and screen readers skip it.

## Select a smaller value

`useRemoteCursors` rerenders its component on every new snapshot of resolved cursors. While cursors move, this is every animation frame. If your component needs less than the full list, use `useRemoteCursorsSelector(select, isEqual?)`.

The hook applies `select` to each snapshot. It rerenders only when `isEqual` reports a change in the selected value. `isEqual` defaults to `Object.is`.

This selector derives the set of clients whose cursor is clipped out of view:

```tsx
function selectClippedClientIds(cursors: ResolvedCursor[]): ReadonlySet<string> {
  const clipped = new Set<string>();
  for (const cursor of cursors) {
    if (cursor.tier === "anchor" && !cursor.pointVisible) clipped.add(cursor.clientId);
  }
  return clipped;
}

function sameClientIds(a: ReadonlySet<string>, b: ReadonlySet<string>): boolean {
  return a.size === b.size && [...a].every((id) => b.has(id));
}

function PresencePill() {
  const clipped = useRemoteCursorsSelector(selectClippedClientIds, sameClientIds);
  return <span>{clipped.size} out of view</span>;
}
```

`selectClippedClientIds` builds a new `Set` on every call. Without `sameClientIds`, the default `Object.is` check rerenders the component on every frame.

<Callout type="warn">
  If `select` or `isEqual` is an inline function, the hook runs `select` again on every render. Declare both
  at module level, or wrap them in `useCallback`.
</Callout>
