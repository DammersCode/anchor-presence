A dialog covers the layout behind it, but a remote cursor can belong to either layer. Two cases need a rule. In the first case, the cursor of a peer is on a card behind your open dialog. In the second case, your cursor is inside a dialog that is closed for the peer. This demo runs that rule with a visibility policy. The cursor itself always paints above the dialog, because `CursorLayer` defaults to `z-index: 9999`.

The demo passes the same policy to both panes through `resolution.visibilityPolicy`. The policy compares the sender's `context` and the resolved `anchorId` with the dialog state of its own pane. The binding reads `bindingOptions` once at creation. For this reason, the policy reads the dialog state through a ref.

## Behavior notes

Try it: Select the Invite button to open the dialog. Select its close button to close it.

- The wide pane runs a team board with an invite dialog. The narrow pane renders the board without the dialog.
- Mira opens the dialog with the context `{ dialog: "invite" }` and points at an anchor inside it. She closes it with the context `{ dialog: null }`. Theo stays on a card behind the dialog.
- While the wide dialog is open, the wide pane hides Theo's cursor: his anchor sits outside the dialog. The narrow pane hides Mira's cursor: her context names a dialog that is closed in this pane.
- Your cursor follows the same rule: while the dialog is open, it only shows where a dialog exists. The open pane hides your cursor on the board behind the dialog. The other pane hides your cursor, because your context names a dialog that is closed in that pane.
- A cursor inside the dialog paints above the dialog, because the z-index of the cursor is higher than the z-index of the dialog. This dialog is not a native modal `<dialog>`. For a native modal dialog, see [Dialogs and transforms](/docs/react/cursor-layer#dialogs-and-transforms).
- The [tour](/docs/examples) opens the dialog from Mira's context as a stand-in for the user of that pane. A real app must not change local UI because of the context of a peer. Open the dialog from a local action instead. See [UI context](/docs/get-started/concepts/ui-context).
- The wide pane shows the dialog while Mira's context is `{ dialog: "invite" }` or you opened it with your button. It closes when Mira's context drops the dialog and you close it. The narrow pane never shows the dialog.
