The provider gets its presence client in one of two ways. Pass a `factory`, and the provider creates and disposes the client. Pass `client`, and you own the client. If your app already creates the client in its own setup code, pass `client`. Otherwise, use `factory`.

## Usage

Pick one path and use it in the whole app:

<Tabs items={["factory (standard)", "Your own client"]}>
<Tab value="factory (standard)">

```tsx
import { createPresenceClient } from "@anchor-presence/core";
import { createWebSocketTransport } from "@anchor-presence/dom";
import { CursorLayer, LiveCursorProvider } from "@anchor-presence/react";

function App() {
  return (
    <LiveCursorProvider
      factory={() => {
        const transport = createWebSocketTransport({ path: "/?room=main" });
        return createPresenceClient({ transport });
      }}
    >
      <CursorLayer />
    </LiveCursorProvider>
  );
}
```

</Tab>
<Tab value="Your own client">

```tsx
import { useEffect, useState } from "react";
import { createPresenceClient, type PresenceClient } from "@anchor-presence/core";
import { createWebSocketTransport } from "@anchor-presence/dom";
import { CursorLayer, LiveCursorProvider } from "@anchor-presence/react";

function OwnClientApp() {
  const [client, setClient] = useState<PresenceClient | null>(null);
  useEffect(() => {
    const created = createPresenceClient({ transport: createWebSocketTransport({ path: "/?room=main" }) });
    setClient(created);
    return () => created.dispose();
  }, []);
  return (
    <LiveCursorProvider client={client}>
      <CursorLayer />
    </LiveCursorProvider>
  );
}
```

</Tab>
</Tabs>

## The factory path

- The provider runs `factory` one time per mount, in an effect. A server render never runs it.
- The provider runs `factory` again each time `clientKey` changes. See [Switch rooms](/docs/react/live-cursor-provider#switch-rooms).
- The provider disposes the client on unmount and before each new `factory` run.
- `client.dispose()` also disconnects the transport.

<Callout type="warn">
  If you create the WebSocket transport at module scope, the first `dispose` disconnects it for good. The next
  client from `factory`, for example the second mount under Strict Mode, then never connects. Create the
  transport inside `factory`.
</Callout>

## The own-client path

- The provider never disposes a client that you pass. Call `client.dispose()` yourself.
- After `dispose`, you cannot use the client again. Create a new client and pass it to the provider.
- The client connects the transport when you create it. To connect later, pass `autoConnect: false` to `createPresenceClient`, then call `transport.connect()`.
- Until your client exists, pass `client={null}`. Every hook then returns its empty value.
- If you set both `factory` and `client`, `client` wins. The factory never runs, and `clientKey` has no effect.
