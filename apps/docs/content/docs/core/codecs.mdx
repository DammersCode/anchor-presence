A codec turns a `PresenceMessage` into bytes for the wire, and turns bytes back into a value. `@anchor-presence/core` ships `jsonCodec`, the default, and `binaryCodec`, a compact codec with a fixed layout. When you set up a room, choose a codec. All clients in the room must use the same one.

## Use a codec

Pass a codec to `createPresenceClient`:

```ts
const client = createPresenceClient({ transport: myTransport, codec: myCodec });
```

When you omit `codec`, the client uses `jsonCodec`.

## Choose a codec

| Codec         | Size of a sample message | Readable in the network tab | Fits                                      |
| ------------- | ------------------------ | --------------------------- | ----------------------------------------- |
| `jsonCodec`   | 292 bytes                | Yes                         | Development, small rooms, easy debugging. |
| `binaryCodec` | 144 bytes                | No                          | Large rooms and many anchors per message. |

The sample message has 4 anchors with two-letter IDs and coordinates with one decimal place. It also has a viewport position and a `user` with a name and a color. Coordinates with more decimal places make the JSON message longer. The binary message keeps its size, because each coordinate is an `f32`. See [Binary codec](/docs/core/binary-codec) for the wire layout and the encode limits.

## Same codec per room

The relay forwards bytes and does not convert between `jsonCodec` and `binaryCodec` frames. A client that decodes the bytes of another codec gets `null`, and `validatePresence` drops the message. In development mode, the client warns one time about the dropped messages.

## PresenceCodec

`@anchor-presence/core` exports `PresenceCodec` with this shape:

```ts
interface PresenceCodec {
  encode(message: PresenceMessage): Uint8Array;
  decode(data: Uint8Array): unknown;
}
```

`decode` returns `unknown`, not `PresenceMessage`, because the client checks the value after the decode. A codec must never throw from `decode`. For malformed input, `decode` returns a value that fails validation, for example `null`.

## jsonCodec

`jsonCodec` works like this code:

```ts
const jsonCodec: PresenceCodec = {
  encode(message) {
    return new TextEncoder().encode(JSON.stringify(message));
  },
  decode(data) {
    try {
      return JSON.parse(new TextDecoder().decode(data));
    } catch {
      return null;
    }
  },
};
```

`decode` catches JSON parse errors and returns `null`. `validatePresence(null)` then returns `null`, and the client drops the message.
