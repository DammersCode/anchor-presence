## createWebSocketTransport

`createWebSocketTransport(options?)` returns a `WebSocketTransport`: a `LiveCursorTransport` from `@anchor-presence/core` whose `connect` and `disconnect` methods are always present, not optional. The transport also implements `subscribeClose`.

If `options.url` is missing and `window` does not exist, `createWebSocketTransport` throws a `TypeError`.

## WebSocketCtor

`WebSocketCtor` overrides the WebSocket constructor the transport uses, and defaults to `globalThis.WebSocket`. A test can supply a fake `WebSocketLike` implementation without touching the real network stack.

The platform `WebSocket` constructor fits `WebSocketCtor` without a cast:

```ts
const transport = createWebSocketTransport({
  url: "wss://relay.example.com/?room=main",
  WebSocketCtor: WebSocket,
});
```
