Your client sends two values to each peer (another client in the same room) together with the cursor. The `user` value says who you are, for example a name and a color. The context value carries small facts about what you do, for example the panel that you have open. `useLocalUser` and `useLocalContext` read these values and give a setter for each. For what context is for, see [UI context](/docs/get-started/concepts/ui-context).

## Usage

This component lets a user change the name that peers see:

```tsx
import { useLocalUser } from "@anchor-presence/react";

type MyUser = { name: string; color: string };

function NameField() {
  const [user, setUser] = useLocalUser<MyUser>();
  return (
    <input
      aria-label="Your name"
      value={user?.name ?? ""}
      onChange={(event) => setUser({ name: event.target.value, color: user?.color ?? "#6366f1" })}
    />
  );
}
```

## Local user

- The setter calls `client.setUser()`, which sends the value to peers.
- The hook rerenders when the value changes. A change is a value with another reference than the current value. A direct `client.setUser()` call also rerenders the hook.
- On the server, and without a client, the hook returns `undefined` and a setter that does nothing.

The default label of `CursorLayer` is the `name` field of this value. See [Defaults](/docs/react/cursor-layer#defaults).

## Local context

This component sets the context while its dialog is open:

```tsx
import { useEffect } from "react";
import { useLocalContext } from "@anchor-presence/react";

function SettingsDialog({ open }: { open: boolean }) {
  const [, setContext] = useLocalContext();
  useEffect(() => {
    setContext({ dialog: open ? "settings" : undefined });
  }, [open, setContext]);
  return open ? <DialogBody /> : null;
}
```

- The setter calls `client.setContext()`, which sends the value to peers.
- The hook rerenders when the value changes. A direct `client.setContext()` call also rerenders the hook.
- On the server, and without a client, the hook returns `undefined` and a setter that does nothing.

Both setters keep their identity while the client stays the same. You can list them in effect dependencies.
