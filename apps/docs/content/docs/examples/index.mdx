Each example page has a live demo with two panes. The panes show the same app in two layouts, a wide one and a narrow one. Move your pointer in one pane, and your cursor appears in the other pane on the same element. The panes connect through a `BroadcastChannel`, so the demos need no server.

<Callout type="warn">
  If you render a color from a remote user, check it first. The examples use `safeColor`, a one-line check for
  a `#rrggbb` value. See [Check the shape of remote
  values](/docs/get-started/guides/security#check-the-shape-of-remote-values).
</Callout>
