A custom codec is your own `CursorCodec`. Write one when you need a wire format that `jsonCodec` and `binaryCodec` do not cover, for example MessagePack. A codec that wraps another codec also lets you log the traffic of `binaryCodec` during development.

## MessagePack sketch

MessagePack makes smaller payloads than JSON for the same data. This sketch uses `@msgpack/msgpack`. Any MessagePack library with an `encode` and `decode` pair on `Uint8Array` works the same way:

```ts
import { encode, decode } from "@msgpack/msgpack";
import type { CursorCodec } from "@anchor-presence/core";

export const messagePackCodec: CursorCodec = {
  encode(message) {
    return encode(message);
  },
  decode(data) {
    try {
      return decode(data);
    } catch {
      return null;
    }
  },
};
```

Wrap every decode call in `try`/`catch`. For a malformed or truncated buffer, `decode` must return `null` and never throw. `encode` can throw. If it throws on a message with `user` or `context`, the client encodes the message again without them. See [Development mode](/docs/core/presence-client#development-mode). If no message encodes, the client drops it.

## Debug binary traffic

The network tab of the browser DevTools cannot show the content of `binaryCodec` frames. Use one of these two options:

<Tabs items={["Switch codec", "Wrap codec"]}>
  <Tab value="Switch codec">
    Use `jsonCodec` in development and `binaryCodec` in production. The network tab then shows every development message as readable JSON.

    <Callout type="warn">
      If a development client and a production client join the same room, each client drops the messages of
      the other. All clients in a room must use the same codec.
    </Callout>

  </Tab>
  <Tab value="Wrap codec">
    This wrapper logs every message and keeps `binaryCodec` on the wire:

```ts
import { binaryCodec, type CursorCodec } from "@anchor-presence/core";

const debugCodec: CursorCodec = {
  encode(message) {
    console.debug("[presence out]", message);
    return binaryCodec.encode(message);
  },
  decode(data) {
    const value = binaryCodec.decode(data);
    console.debug("[presence in]", value);
    return value;
  },
};
```

  </Tab>
</Tabs>

The browser console has no `binaryCodec` global. To read one captured frame in the console, expose the codec in development, for example `globalThis.binaryCodec = binaryCodec`. Then call `binaryCodec.decode(new Uint8Array([/* bytes */]))`.
