This page takes you from an empty React app to live cursors in two steps. First, you connect two windows of one browser with no server. Then you connect two browsers through a relay. Install the packages first. See [Installation](/docs/get-started/installation).

To get an empty app, run `bun create vite my-app --template react-ts`. Put the sample in `src/App.tsx`.

## Try it in two windows

<Steps>
<Step>

### Create the client and the provider

`createBroadcastChannelTransport` connects the tabs of one browser, with no server. The `factory` prop of the provider creates the client. One element carries `data-anchor`:

```tsx
import { createPresenceClient } from "@anchor-presence/core";
import { createBroadcastChannelTransport } from "@anchor-presence/dom";
import { CursorLayer, PresenceProvider } from "@anchor-presence/react";

function createClient() {
  const transport = createBroadcastChannelTransport("live-cursors");
  return createPresenceClient({ transport, user: { name: `Guest ${Math.floor(Math.random() * 100)}` } });
}

export default function App() {
  return (
    <PresenceProvider factory={createClient}>
      <button data-anchor="nav.dashboard">Dashboard</button>
      <CursorLayer />
    </PresenceProvider>
  );
}
```

</Step>
<Step>

### Open two windows

Open your app in two windows of the same browser, side by side. To get the second window, drag a tab out of the window. Move the pointer over the button in one window. A cursor with a guest name appears in the other window.

When its window loses focus or the pointer leaves the page, the sender clears its cursor. For this reason, two tabs in one window never show each other a cursor.

</Step>
</Steps>

`CursorLayer` shows `user.name` as the label. It gives each client [one of 8 colors](/docs/react/cursor-layer#defaults).

<Callout type="warn">
  If you create the client at module scope, the server also runs that code, and all requests share one client.
  Create the client in `factory`. The provider runs `factory` in the browser only, once per mount, and
  disposes the client on unmount. See [SSR and Strict Mode](/docs/react/ssr-and-strict-mode).
</Callout>

## Connect a relay

A `BroadcastChannel` never leaves the browser. To connect two browsers or two devices, use a relay and `createWebSocketTransport`. Before you run a relay in production, read [Deploy a relay](/docs/get-started/guides/deploy-relay).

<Steps>
<Step>

### Start a relay

Start the [Bun relay](/docs/examples/backends/bun-native) from a clone of the repository. It listens on port 8788:

```sh
bun install
cd examples/bun-native
bun run dev:relay
```

</Step>
<Step>

### Change the transport

Change only the transport in `createClient`:

```tsx
import { createPresenceClient } from "@anchor-presence/core";
import { createWebSocketTransport } from "@anchor-presence/dom";

function createClient() {
  const transport = createWebSocketTransport({ port: 8788, path: "/?room=main" });
  return createPresenceClient({ transport, user: { name: `Guest ${Math.floor(Math.random() * 100)}` } });
}
```

The client connects the transport when you create it. `room` is a query parameter that the relay reads to group clients. It is not part of the protocol. Each relay in [Backends](/docs/examples/backends) uses its own port, so set `port` to the port of your relay. Without `port`, the transport connects to port 8787, the port of the [reference relay](/docs/examples/backends/relay-contract). This page uses the Bun relay on port 8788.

</Step>
<Step>

### Open two windows

Open your app in two browser windows of different widths. Move the pointer in one window. The cursor stays on the same element in the other window.

<Demo />

</Step>
</Steps>

## Test with more users

Each extra window is one more user. Only the window under the pointer sends a cursor, so each window shows one moving remote cursor at a time. To see two at once, add a second device, for example a phone. To open the app on a phone, start the dev server with `bun run dev --host`, and open the network address on a phone that uses the same network. Then use a relay, because a `BroadcastChannel` never leaves the browser. For tests with no browser, see [Test with more than two peers](/docs/core/in-memory-transport#test-with-more-than-two-peers).

## Without React

`@anchor-presence/core` and `@anchor-presence/dom` work with no React. `createDomBinding` gives the resolved cursors, and you render them with plain DOM code or another framework. See [Draw cursors without React](/docs/dom/binding#draw-cursors-without-react). To connect the binding to another framework, see [Build a framework adapter](/docs/core/build-a-framework-adapter).
