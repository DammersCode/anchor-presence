# Docs design rubric

Scored 1-10 per dimension by fresh scorers who read the built pages. 7 = acceptable, 9 = strong, 10 = nothing to change. Evidence (page path, quote) is required for every score below 9.

| Dimension     | 9 means                                                                                                                                                  |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Structure     | Every page follows one template: what it is and when to use it, a minimal working example, details, related links. Sections are short and scannable.     |
| Visual design | Sidebar and index pages carry icons. Index pages use Cards. Steps, Tabs, Callouts, Files, and Accordions are used where they help, and not decoratively. |
| Text          | Plain, short, precise sentences (simple-english). No jargon without a definition. No filler. Every claim matches the code.                               |
| Navigation    | A reader finds any task in at most two clicks. Page order follows the learning path. Related links connect neighbours.                                   |
| Examples      | Every concept has a runnable sample that compiles. Live demos appear where motion or layout matters.                                                     |
| Completeness  | Every public export, option, and error is documented once, in one place.                                                                                 |
| Trust         | Honest about limits: what is tested, what is not, known caveats. No stale names.                                                                         |

Overall docs score = the mean, rounded to 0.5. Goal: at least 9 and no dimension below 8.
